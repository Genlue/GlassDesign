## 3. 六条链（架构）

改动前先确认你动的是哪条链。**六条链之间只通过 CSS 变量、`data-*` 和公开 props 交互**，跨链改动的成本高一个量级。

### 3.1 材质链（构建期 → 静态 filter）

```text
scripts/glass/*.js ──build-glass.mjs──▶ 位移图 + 高光图 (PNG/base64)
                                     ├▶ 控件/assets/glass-defs.svg（<filter>）
                                     └▶ 63-glass-svg.css（选择器 + backdrop-filter）
install() ──注入──▶ <style id="gd-styles"> + <div id="gd-glass-defs">
组件只写 class / data-glass ──▶ backdrop-filter: blur(...) saturate(...) url(#gd-glass-panel-480x320)
```

**11 档**：胶囊 34/112/180、滑块拇指 24×16、面板 320×220 / 480×320 / 640×420、菜单 240×200 / 240×280、Sheet 520×360、Toast 320×34。
没命中档位的走 `Auto`（纯 CSS 材质，无位移折射）。

### 3.2 主题链（只写变量）

```text
Theme::provide() ──Effect──▶ <html data-theme="light|dark" data-theme-mode="system">
                             └▶ --accent* / --lg / --shadow-k / --ic-stroke / --text-on-accent
```

### 3.3 浮层几何链（Portal + 锚定层）

```text
组件只决定「开 / 关」
  └▶ <Portal>          面板挂 body，脱离祖先的 transform / backdrop-filter 包含块
  └▶ Effect(open)      anchor::place_and_apply(触发器, 面板, spec)
        ├ 量内容高（临时放开 max-height）→ 下方放不下且上方更宽裕就翻上
        ├ 左右夹进视口（margin 8）→ 写 left/top/width/max-height + data-side
        └ anchor::watch：scroll(capture) + resize + ResizeObserver，rAF 合帧重算
```

### 3.3.1 仲裁（同一串之外只留一层）

```text
新层 push_child(kind, parent, on_dismiss)
  ├ 祖先链 = chain(parent)                     子菜单声明父菜单 → 父层永不被自己的子层收掉
  ├ 待收 = 非模态层 − 祖先链                   模态层永不参与（对话框不互相关）
  ├ 每棵无关子树只取根 → 回调 on_dismiss        父层收起会带子层，重复回调会二次改状态
  └ 先入栈、再回调                              被收的那层要能在栈上看见新层
```

`push(kind, cb)` 就是 `parent = None`。**父链只能显式声明**：判断不出「谁是谁的容器」，
靠猜就会把父菜单一起关掉 —— 这也是当初没做这件事的原因。

### 3.4 虚拟化链（一份窗口算法，三处复用）

```text
scroll ──▶ window_of(容器, 行高, 总行数, OVERSCAN) ──▶ Window[start, end)
                                                       ├ 渲染 [start*cols, end*cols)
                                                       ├ 上留白 = start × 行高
                                                       └ 下留白 = (total − end) × 行高
```

行高必须固定，且 CSS 与 Rust 读同一个数（`--dt-row-h` / `--tree-row-h` / `--item-pitch` 由 prop 写进内联样式）。

### 3.5 焦点链

`OverlayHost`（`base/overlay.rs`）是唯一权威：z 栈、Esc 只关栈顶、模态焦点陷阱、背景 `inert`、关闭归还焦点。
列表类组件用 roving tabindex（只有一个 `tabindex="0"`）；虚拟化后**先滚进视口再聚焦**，并 `focus({preventScroll:true})`。

**同 rank 仲裁会让「焦点归还」变成抢焦点**：A 被 B 挤掉时，A 的关闭逻辑会把焦点还给 A 的触发器，
正好落在 B 刚聚焦完的下一帧。所以归还要过 `focus_is_free(own)`：只在「焦点还在自己面板里，或已经空着」
时才还 —— 判定看 DOM 不看栈，且放在真正 `focus()` 的那一帧做。

### 3.6 状态链

受控值走 `MaybeProp<T>`，回调用 `Option<Callback<T>>`；选择状态在 `widgets/selection.rs`（单选/多选/Shift 连选/Ctrl 切换），
组件内部只留 `SelectionState` 的副本，变更后把完整选中集交回调用方。

## 4. 红线（七条，破了可复制性就没了）

1. **`控件/` 是唯一复制单元**：不许引用 `应用/`、`scripts/`、`docs/`、`target/`。
2. **外观只走令牌与类名**：Rust 里不出现字面色值、字号、圆角、阴影；动态几何（`top/left/height`）除外。
3. **材质只由固定尺寸档触发**：组件只写 `class` / `data-glass`，不在运行时算滤镜。
4. **任何 `position: fixed` 的浮层必须 `<Portal>`**：留在组件 DOM 里就会踩包含块。
5. **虚拟化行高必须固定**，并且 CSS 与 Rust 用同一个数。
6. **不改 CSS 分区文件的既有规则**，需要补充就**追加**到对应分区末尾并写清原因；不新建分区、不改 `components.css` 的 import 顺序。
7. **`prelude` 是唯一公开出口**：新增组件必须在 `lib.rs` 导出，否则等于没做。

## 6. 常见任务

### 6.1 加一个组件

1. `控件/src/widgets/xxx.rs`：`#[component] pub fn Xxx(...) -> impl IntoView`。
2. props：`#[prop(into, optional)]`；受控值 `MaybeProp<T>`，回调 `Option<Callback<T>>`。
3. **只写既有类名**：先去 `控件/css/src/components/` 找对应分区。
4. `widgets/mod.rs` 加 `pub mod xxx;`。
5. `lib.rs` 的 `prelude` 导出（红线 7）。
6. `cargo check -p glass-design --target wasm32-unknown-unknown`。
7. 画廊 `应用/ui/src/pages/` 对应分区加活体样例。
8. 更新 `docs/03-实现清单.md` 与 `控件/变更.md`。
9. 动了 CSS：`node scripts/build-css.mjs` → **再强制重编 crate**（`touch 控件/src/base/install.rs` 最稳）。

**参考模板**：`button.rs`（简单受控）、`slider.rs`（拖拽 + 键盘 + 无测量布局）、`select.rs`（Portal + 定位）、`data_table.rs`（虚拟化 + 拖拽列宽）。

### 6.2 加一个玻璃尺寸档

1. `scripts/build-glass.mjs` 的 `SHAPES` 加一条 `{ id, surface, w, h, r, css, blur, tier }`。
   `surface` 必须是 `glass-schema.js` 里已有的面；`r` 必须与该元素 CSS 的圆角**完全一致**，否则会看到「双重边」。
2. `node scripts/build-glass.mjs && node scripts/build-css.mjs`。
3. Rust 侧写 `data-glass="<id>"`（`GlassPanel` 之类由枚举给出）。
4. 截图确认：`node scripts/shot-el.mjs <url> "<selector>" out.png 6`。

### 6.3 改主题令牌 / 改玻璃观感

- 颜色、尺寸、模糊：`控件/css/src/tokens.css`（只改变量，不加规则）。
- 折射强度、色散、高光：`scripts/glass/glass-schema.js` → 重跑 `build-optics.mjs` + `build-glass.mjs`。

### 6.4 重生成静态快照

```sh
cd 应用/ui/dist && python -m http.server 8777   # 另开终端
cd ../../.. && node scripts/build-static.mjs
```

它用无头 Chrome `--dump-dom` 抓**渲染后**的 DOM，剥掉 `<script>`，写成根目录 `index.html`。
快照是**生成物的生成物**：控件改了没重跑这一步，`index.html` 就是旧的。

### 6.5 换 Leptos 版本

公开 API 不暴露框架类型，所以只需改 `控件/Cargo.toml` 的 `=x.y.z`，然后全仓 `cargo check`。
重点看三处：`Callback` / `MaybeProp` 的语义、`Portal` 的签名、`NodeRef` 的 `.get()` 返回类型。

## 7. 踩过的坑（14 条，每条都真踩过）

| # | 现象 | 原因 | 破法 |
|---|---|---|---|
| 1 | release wasm 27.9 MB | 默认带 name 段（24 MB 符号名） | `wasm-bindgen --remove-name-section --remove-producers-section` |
| 2 | 改了 CSS 页面没变 | `include_str!` 变化本机不触发重编 | 重跑 `build-css.mjs` 后 `touch 控件/src/lib.rs` |
| 3 | 面板跑到别处 / 跟着容器滚 | 祖先有 `transform`/`filter`/`backdrop-filter`，成了包含块 | 面板一律 `<Portal>` + `anchor` 视口坐标（红线 4） |
| 4 | 点菜单项反而把菜单关了 | 面板已 Portal 到 body，`root.contains()` 判成点外 | 判定要同时认「触发器 ∪ 面板 ∪ 子菜单」 |
| 5 | 滚一格跳两格 | 滚动锚定（`overflow-anchor`）在撑高行增长时又补一次 | 虚拟滚动容器 `overflow-anchor: none` |
| 6 | 连按 ↓ 每 7 行被拽回中间 | `focus()` 默认把目标居中滚 | `focus({preventScroll:true})` + 自己算最小滚动 |
| 7 | 滚到底部一片空白 | `scrollTop` 超出总高，窗口 `start > total` 塌成空 | `window()` 把 start 也夹回 total（有单测） |
| 8 | 大纲缩进忽左忽右 | 有图标/无图标行文字起始线差一个图标宽 | 图标位固定 13px（`.c-outline__lead`） |
| 9 | 子菜单错位或被裁 | `.c-menu` 自带 `backdrop-filter` + `overflow:hidden` | 子菜单独立 Portal + 独立 `OverlayId` |
| 10 | Esc 关掉子菜单又自己弹回来 | 悬停 300ms 计时器在关闭之后才触发 | 关闭入口清掉本层计时器 |
| 11 | 点外部控件没反应 | `DatePicker`/`ColorWell` 的全屏遮罩吞了点击 | 删遮罩，改文档级 `pointerdown` 判定 |
| 12 | 虚拟列表底部多一条 4px 缝 | 0 行的撑高行仍占一个 gap | `data-rows="0"` 时 `display:none` |
| 13 | 集合虚拟化后列宽变了 | 绝对定位模式要复刻 padding/gap | 保留静态 grid + 跨行撑高行 |
| 14 | `pub mod virtual;` 编译不过 | `virtual` 是保留字 | 模块名用 `virtual_window` |
| 15 | 开第二个菜单后键盘失灵（焦点跳回第一个触发器） | 被挤掉的那层在 rAF 里归还焦点，晚于新层聚焦 | 归还要过 `focus_is_free(own)`，且判 DOM 不判栈 |

### 8.2 交互断言（按分区点一遍）

| 表单 | 下拉 / 日期 / 取色 | 面板贴触发器下方 6px；滚到视口底再开 → 翻上（`data-side="above"`） |

### 8.3 为什么对齐类缺陷要用矩形比对

肉眼在 1x 截图上会看错 2–6px（字形宽度、居中、亚像素都会骗你）。
一律用 `getBoundingClientRect()` 逐列/逐行比对，例如表头与首行单元格的 `x` 必须逐个相等：

```js
const t = document.querySelector('.c-datatable');
const ths = [...t.querySelectorAll('thead th')].map(e => Math.round(e.getBoundingClientRect().x));
const tds = [...t.querySelectorAll('tbody tr')[0].children].map(e => Math.round(e.getBoundingClientRect().x));
JSON.stringify(ths) === JSON.stringify(tds);   // 必须 true
```
