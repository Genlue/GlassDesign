## 4. 五个关键决策

### 4.1 Leptos 0.8.23（CSR），不是 Dioxus / Yew / 保留 JS

- **理由**：`view!` 与现有 CSS 类名一对一，迁移是「翻译」不是「重新设计」；细粒度 signals 正好对应旧库的 `set/value` 命令式契约；不绑定 CLI / 路由 / 资源系统；WASM 产物可直接塞进 Tauri，不需要 node 工具链。
- **代价**：作者 2026-05 声明「轻维护」，0.9 在 RC。
- **兜底**：锁 `=0.8.23`（不是 `^`），不追 0.9；公开 API 不暴露 `leptos::` 类型（`Signal` / `Callback` 除外）；换框架时只改组件内部，调用方不动。
- **反悔成本**：高，但局限在 `控件/src/`，CSS 与材质不用动。

### 4.2 材质只在构建期算，运行时零脚本

- **理由**：用户明确要求「脱离外部渲染 core」「无 JavaScript」「无 WebGL」。静态 filter 同时满足三者，且换来两个好处：CSP 可以严到不放开 `unsafe-eval`；换主题不重建任何东西。
- **代价**：**做不出随尺寸自适应的真折射**（见 4.3）；改变折射强度要重新生成贴图，不能运行时调参。
- **已花的成本**：删掉了 `glass-lens` 的挂载器、`refraction.js`、`js/` 目录、`build-engine.mjs`。

### 4.3 玻璃按固定尺寸档，不是「一张图通吃」

- **实测结论**（本机 Chrome，WebView2 同源）：`backdrop-filter: url(#filter)` **可用**；但 `feImage` **不会**把预计算贴图按元素框拉伸——给 `width="100%"` 得到的是贴图固有尺寸，套到不同宽度的元素上会硬切、局部不滤波。
- **因此**：贴图尺寸必须与元素尺寸**逐像素一致**，玻璃组件只能按档位做。
- **代价**：`CapsuleSize::Auto` 没有折射，只有 CSS 涂层。
- **扩展方式**：往 `scripts/build-glass.mjs` 的 `SHAPES` 加一条 → 重跑 → 在 Rust 枚举加一档。加档位是廉价的，不要试图做「任意尺寸」。

### 4.4 只做 Windows

- **理由**：用户明确要求。旧库本身是 Electron 特化（透明窗口、红绿灯、标题栏），三端一致本来就要降级材质。
- **代价**：macOS/Linux 不承诺，也没测过。
- **如果将来要扩**：CSS 兜底路径已经存在（`CapsuleSize::Auto`），能跑但没折射；`backdrop-filter` 在 WebKit 上对 `url()` 的支持要重新实测。

### 4.5 `控件/` 是唯一复制单元

- **理由**：用户的核心诉求——「别的项目直接整个复制过去，拼凑法拼界面，需要时替换该文件夹」。
- **实现**：样式与贴图 `include_str!` 编进 crate，所以**不需要拷第二处资源**；`install()` 自带注入，所以**不需要改宿主配置**。
- **硬约束**：见 §5。破了任何一条，「整个文件夹复制」就不成立。

## 5. 硬规矩（七条，破了可复制性就没了）

1. **`控件/` 不许 import 仓库里的 `应用/`、`scripts/`、`docs/`。** 它必须能单独打包。
2. **不许依赖运行期文件路径。** 样式、贴图、图标一律 `include_str!`。
3. **不许出现第三个全局单例。** 只允许 `Theme`（context）与 `Toast`（thread_local 队列）。
4. **不许在 Rust 里写字面色值 / px / 圆角 / 阴影。** 新值先加进 `css/tokens.css`。
5. **不许把 `leptos::` 类型暴露给调用方**（`Signal` / `Callback` 除外）。
6. **不许改 DOM 契约而不改 major。** 类名、`data-*`、ARIA、键盘行为都算契约。
7. **不许用一张贴图通吃所有尺寸。** 玻璃尺寸必须落在档位表里，否则走 `Auto` 纯 CSS。

版本规则：加 prop / 加组件 = minor；改 props 形状、删组件、改 DOM/键盘契约、改贴图尺寸 = major。

## 6. 常见任务怎么做

### 6.1 加一个组件

1. `控件/src/widgets/xxx.rs`：`#[component] pub fn Xxx(...) -> impl IntoView`。
2. props 一律 `#[prop(into, optional)]` / `#[prop(optional)]`；受控值用 `MaybeProp<T>`，回调用 `Option<Callback<T>>`。
3. **只写既有类名**。先去 `控件/css/src/components/` 找对应分区，不要新造样式。
4. `widgets/mod.rs` 加 `pub mod xxx;`。
5. `lib.rs` 的 `prelude` 加导出（公开 API 只有这一处）。
6. `cargo check -p glass-design --target wasm32-unknown-unknown`。
7. 在 `应用/ui/src/pages/` 对应分区加活体样例。
8. 更新 `docs/03-实现清单.md` 与 `控件/变更.md`。

**参考模板**：`button.rs`（简单受控）、`switch.rs`（受控布尔）、`slider.rs`（拖拽 + 键盘 + 无测量布局）、`checkbox.rs`（roving 焦点）。

### 6.2 加一个玻璃尺寸档

1. `scripts/build-glass.mjs` 的 `SHAPES` 加一条：`{ id, surface, w, h, r, css, blur }`。
   - `surface` 必须是 `glass-schema.js` 里已有的 8 个之一（`capsule / panel / menu / sheet / toast / dock / thumb / ...`）。
   - `css` 是选择器，必须**精确命中**目标元素。
2. `node scripts/build-glass.mjs && node scripts/build-css.mjs`。
3. 若该尺寸需要 Rust 侧表达，在对应枚举（如 `CapsuleSize`）加一档并写 `data-size`。
4. 截图确认：`node scripts/shot-el.mjs <url> "<selector>" out.png 6`。

### 6.3 加图标

`node scripts/gen-icons.mjs "../Golden Gate HTML Design/scripts/core/icons.js"` — 从旧库读 97 个图标生成 `icon.rs`。要用新图标，先改旧库的 `icons.js`（或直接改生成脚本的来源参数）。

### 6.4 改主题令牌

- 颜色/尺寸/模糊：改 `控件/css/src/tokens.css` → 跑 `build-css.mjs`。
- 8 套玻璃参数：改 `scripts/glass/glass-schema.js` 的默认值 → 跑 `build-optics.mjs` **和** `build-glass.mjs`（贴图里编码了参数，只跑前者会导致涂层与位移不一致）。
- 强调色：`Theme::set_accent("#...")`，`apply_accent()` 会派生 hover / soft / ring / on-accent。

### 6.5 重新生成静态预览

```sh
cd 应用/ui/dist && python -m http.server 8777    # 另开一个终端
cd ../../.. && node scripts/build-static.mjs
```

它会用无头 Chrome `--dump-dom` 抓**渲染后**的 DOM，剥掉 `<script>` 与引擎脚本，写成根目录 `index.html`。
注意：快照是**生成物的生成物**，控件改了但没重跑这一步，`index.html` 就是旧的。

### 6.6 换 Leptos 版本

改 `控件/Cargo.toml` 与 `应用/ui/Cargo.toml` 的 `=0.8.x` → `cargo update -p leptos` → 全量重编。
`wasm-bindgen` 必须与 `wasm-bindgen-cli` **完全同版本**，否则 `wasm-bindgen` 命令会拒绝处理。

## 7. 踩过的坑（省你半天）

| 坑 | 现象 | 处置 |
|---|---|---|
| Cargo 代理指向 `127.0.0.1` 的死端口 | `cargo add` / 拉依赖超时，报连接被拒 | 已在仓库 `.cargo/config.toml` 写 `[http] proxy = ""`。**别删这个文件** |
| `feImage` 不拉伸 | 贴图套到别的尺寸，边缘硬切、部分区域不滤波 | 固定尺寸档；见 §4.3 |
| Leptos `Show` + `Portal` 的 FnOnce 约束 | `Dialog` 编译报 closure 只能调用一次 | 改成常驻 DOM + `style` 切 `display:none`，不用 `Show` 包 `Portal` |
| 下拉被卡片 `overflow` 裁掉 | 菜单只露一条 | 菜单改 `position:fixed`，打开时读 trigger 的 `getBoundingClientRect()` 定位 |
| 滑块依赖 JS 写 `--travel` | 没有测量就没有位置 | 新增 `64-slider-leptos.css`，用 `left: calc(... var(--p))` 纯 CSS 定位 |
| `Field` 只写了 `prop:value` | 静态快照里输入框是空的 | 同时写 `value` 属性；但 `TextArea` 会因此编译错，注意区别处理 |
| wasm 体积 | release `.wasm` 4.9 MB，wasm-bindgen 输出 11 MB | gzip 后 715 KB，实际传输可接受；要更小加 `wasm-opt -Os`，**未做** |
| Tauri 调试端口 | 想用 CDP 截图必须开 `additionalBrowserArgs` | 用完**务必删掉**再提交，否则线上包也开着调试端口 |
| 快照与源码不同步 | `index.html` 显示旧内容 | 每次改控件后重跑 `build-static.mjs` |
| 中文路径 | 脚本/命令里的 `控件/`、`应用/` | Node 与 bash 都已验证可用；但**不要在 Windows 上写 `.ps1`/`.bat` 处理中文路径** |

## 9. 下一步：P3 的顺序与理由

**先做材质尺寸表，再做重型控件。** 理由：控件一旦按「无折射」的观感定稿，后面加档位要重新对视觉；反过来先定档位，控件直接按有折射的样子拼。

1. **面板 / 菜单 / 模态 / 提示条 / Dock 的尺寸档**（半天，收益最大）
   定 3–5 个常用尺寸写进 `SHAPES`：如 `panel 320×220`、`panel 480×320`、`menu 240×280`、`sheet 520×360`、`toast 320×44`。
2. **`OverlayHost`**：现在 `Dialog` 与 `Select` 各写一套 `z-index` 与关闭逻辑，超过 2 层就会互相压。合并成单栈后再做 `Menu / Popover / Tooltip`。
3. **`RangeSlider`**：复用 `Slider` 的状态机，加双拇指与「谁离得近谁动」的判定。
4. **`Combobox`**：复用 `Select` 的固定定位 + 键盘模型，加输入过滤。
5. **`DataTable`**：在 `Table` 上叠列宽、列序、虚拟行——**先做非虚拟**，量到性能问题再上窗口化。
6. **`TreeView` / `CollectionView`**：同上，先非虚拟。
7. **`DatePicker` / `TimePicker`**：日期网格 + 分段光标。
8. **`Inspector` / `SplitView` / `StatusBar`**：面板组合，依赖 `OverlayHost` 与尺寸档。

**不建议现在做**的：`ToolbarCustomization`（拖拽重排 + 持久化，依赖未定）、`ToolbarOverflow`（需要测量，等尺寸稳定）、`Form`（等字段类控件齐了再编排）。

## 10. 风险账本

| 风险 | 影响 | 触发条件 | 处置 |
|---|---|---|---|
| Leptos 轻维护 / 0.9 破坏性变更 | 中 | 需要新特性或安全修复 | 锁 `=0.8.23`；公开 API 不暴露框架类型；换框架只动 `控件/src/` |
| 玻璃档位膨胀 | 中 | 每个新尺寸都要一张贴图 | 档位表集中在一处；`Auto` 兜底；不要让每个控件自定义尺寸 |
| 焦点问题 | **高** | 声明式重建天然丢焦点 | 至少 8 个旧控件手工搬 `activeElement`；新组件必须写「焦点 key + 恢复」 |
| 无同步布局 | 中 | Rust/WASM 拿不到同步测量 | CSS 优先 → 两阶段渲染 → 接受一帧延迟；不要试图在 render 里量 |
| WebView2 与旧 Electron 像素不一致 | 低 | 用户拿旧截图对比 | 已确认静态 filter 可渲染；逐像素对照未做，也不要承诺 |
| 中文目录 + Windows 工具链 | 低 | CI / 脚本 | 已在 Node 与 bash 验证；避免 `.bat`/`.ps1` |
| 快照腐化 | 低 | 忘跑 `build-static.mjs` | 每次改动后重跑；`index.html` 顶部有生成说明 |

## 12. 还没定的事

1. **`控件/` 要不要独立成 git 仓库 + 子模块？** 现在是同仓库子目录，复制靠手动拷。若要跨项目共享，建议拆仓 + 语义化 tag。
2. **要不要上 `wasm-opt`？** 现在 gzip 715 KB 可接受；上 CDN 或弱网才值得。
3. **`Dialog` 焦点陷阱要不要现在补？** 它影响所有后续浮层；`OverlayHost` 一起做更划算。
4. **`index.html` 要不要保留？** 它是视觉快照，不参与构建，好处是「打开就能看」。若仓库体积敏感可删，用 `build-static.mjs` 随时重生。
5. **旧库要不要打 tag 归档？** 现在是「冻结但可读」，建议打 `legacy-final` tag，避免误改。
