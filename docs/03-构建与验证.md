## 2. 构建管线

材质、样式、图标都在**构建期**算完，产物落到 `控件/` 里，运行期只读它们。

```text
scripts/glass/{schema,shape,optics}.js
   │
   ├─ build-optics.mjs ──▶ 控件/css/src/optics.css        每面玻璃的默认变量
   ├─ build-glass.mjs  ──▶ 控件/assets/glass-defs.svg     位移/高光贴图 + <filter>
   │                   └─▶ 控件/css/src/components/63-glass-svg.css
   └─ gen-icons.mjs    ──▶ 控件/src/base/icon.rs          97 个 path

控件/css/src/{tokens,optics,base,layout,components}.css
   └─ build-css.mjs ──▶ 控件/css/glass.css                @import 展开成单文件（316 KB）

控件/src/**  +  glass.css  +  glass-defs.svg
   └─ cargo build(wasm32, release) ──▶ target/…/glass_design_gallery.wasm
        ├─ wasm-bindgen --target web        ──▶ 应用/ui/dist/{*.js,*.wasm}     本地服务器用
        └─ wasm-bindgen --target no-modules ──▶ 应用/ui/dist/nm/{gd.js,gd_bg.wasm}
             └─ build-standalone.mjs ──▶ index.html（wasm gzip+base64 内联）
```

### 2.1 完整命令

```sh
cd "C:/Users/25659/Desktop/Project/GlassDesign"

# ① 样式与材质
node scripts/build-optics.mjs
node scripts/build-glass.mjs
node scripts/build-css.mjs
node scripts/gen-icons.mjs      # 只有要重生成图标时才跑

# ② wasm（release 默认带 24 MB 符号名，两个 --remove-* 不能省）
cargo build -p glass-design-gallery --target wasm32-unknown-unknown --release

wasm-bindgen --target web --no-typescript --remove-name-section --remove-producers-section \
  --out-dir 应用/ui/dist target/wasm32-unknown-unknown/release/glass_design_gallery.wasm

wasm-bindgen --target no-modules --no-typescript --remove-name-section --remove-producers-section \
  --out-name gd --out-dir 应用/ui/dist/nm target/wasm32-unknown-unknown/release/glass_design_gallery.wasm

# ③ 两种看法
node scripts/preview.mjs            # http://127.0.0.1:8777 —— 开发用
node scripts/build-standalone.mjs   # → index.html（1.42 MB，双击可交互）

# ④ 只读快照（可选；需要 8777 在跑）
node scripts/build-static.mjs       # → index-static.html

# ⑤ 宿主
cargo build -p glass-design-app && ./target/debug/glass-design-app.exe
```

**改了 `控件/css/src/**` 之后必须 `touch 控件/src/lib.rs` 再编译。** 样式用 `include_str!` 编进 crate，文件内容变了本机 cargo 不一定重编——这是最容易漏的一步，漏了就会以为"改了没生效"。

### 2.2 产物

| 文件 | 大小 | 谁生成 | 用途 |
|---|---|---|---|
| `控件/css/glass.css` | 313 KB | build-css | 唯一 CSS 入口 |
| `控件/assets/glass-defs.svg` | — | build-glass | 11 个静态 `<filter>` |
| `应用/ui/dist/*.js / *.wasm` | 62 KB / 3.32 MB | wasm-bindgen web | 本地服务器 |
| `应用/ui/dist/nm/*` | 68 KB / 3.32 MB | wasm-bindgen no-modules | 单文件打包的原料 |
| `index.html` | 1.42 MB | build-standalone | **双击即用的交互预览** |
| `index-static.html` | 697 KB | build-static | 只读快照（无 JS） |

`应用/ui/dist/` 里只有 `index.html`（壳层模板 + 样式）是**源**，其余都是产物。它被 `.gitignore` 特意放过，别的都忽略。

### 2.3 宿主 crate（`host/`）

`host/` 是 `glass-design-host`，把「Tauri 窗口怎么装、桌面怎么截」从 `应用/src-tauri` 里拆出来，供别人复用。

```sh
cargo check -p glass-design-host          # Windows 上带 windows crate
cargo build -p glass-design-app           # 画廊宿主，依赖 host
```

依赖方向是单向的，改的时候别绕回去：

```text
应用/src-tauri ──▶ glass-design-host ──▶ tauri / windows / png / base64
       │
       └────────▶ glass-design（只有 ui 侧依赖，宿主不需要）
```

- `host` **不依赖** `控件/`：它只负责宿主壳层与壁纸接线（写 `data-shell="host"` 并提供向后兼容的命令/入口），不碰组件，也不碰 CSS。
- `控件/` **不依赖** `host`：库必须能编到 `wasm32-unknown-unknown`。
- `host` 仅依赖 `tauri`，所有平台都能正常编译（不再依赖 Win32 GDI 截屏或 `WDA_EXCLUDEFROMCAPTURE`）。

CI 上不构建 `host`：GitHub 的 ubuntu runner 没有 WebView2 / Win32，且 `tauri` 的系统依赖装不全。CI 只 `cargo check -p glass-design`。

## 3. 三种看法的分工

| 方式 | 怎么开 | 有什么 | 没有什么 |
|---|---|---|---|
| 本地服务器 | `node scripts/preview.mjs` | 全部交互与动效，热改热看 | 需要起进程 |
| 单文件 | 双击 `index.html` | 全部交互与动效 | 改代码后要重新打包 |
| 只读快照 | 双击 `index-static.html` | 九个分区的版式，可切页/切明暗 | 任何控件交互 |

单文件预览把 wasm 以 `gzip + base64` 内联，用 `DecompressionStream` 解压后 `initSync` 实例化。`file://` 下 `import` 与 `fetch(wasm)` 都会被 CORS 拦掉，这是唯一可行的路。

### 3.1 宿主（Tauri）

窗口不透明、无边框。背景由页面最底层的合成渐变 `#wallpaper`（`tokens.css` 的 `--wallpaper` / `data-source="demo"`）提供，不再使用 `WDA_EXCLUDEFROMCAPTURE` 或桌面实时截屏，从而保证远程桌面、系统截图、录屏与任务栏预览正常工作且不会触发驱动黑屏。`wallpaper.js` 仅在检测到 `window.__TAURI__` 时打开 `data-shell="host"`（全铺无边框壳层）并确保 `#wallpaper` 停留在合成渐变背景上。

**调试宿主**：临时在 `tauri.conf.json` 的窗口里加
`"additionalBrowserArgs": "--remote-debugging-port=9222"`，重编后即可用 CDP 连
`http://127.0.0.1:9222/json/list` 截图 / 取状态（环境变量
`WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS` 对 Tauri 无效，它自己会设 args）。
测完记得删掉这行 —— 它是个后门。

**注意 CDP 截图看的是渲染器输出，绕过了 DWM 合成**。窗口层面的问题
（分层窗口对齐、DPI 重协商）在 CDP 截图里是看不见的，只能看真实屏幕。

## 4. 加东西的流程

### 4.1 加一个组件

1. `控件/src/widgets/xxx.rs`：`#[component] pub fn Xxx(...) -> impl IntoView`。
2. props：`#[prop(into, optional)]`；受控值 `MaybeProp<T>`，回调 `Option<Callback<T>>`。
3. **只写既有类名**：先去 `控件/css/src/components/` 找对应分区。
4. `widgets/mod.rs` 加 `pub mod xxx;`。
5. `lib.rs` 的 `prelude` 导出（否则等于没做）。
6. `cargo check -p glass-design --target wasm32-unknown-unknown`。
7. 画廊 `应用/ui/src/pages/` 加活体样例。
8. 更新 `docs/02` 的组件清单与边界表。

参考模板：`button.rs`（简单受控）、`slider.rs`（拖拽 + 键盘 + 无测量布局）、`select.rs`（Portal + 定位）、`data_table.rs`（虚拟化 + 拖拽列宽）。

### 4.2 加一档玻璃

1. `scripts/build-glass.mjs` 的 `SHAPES` 加一条：`{ id, surface, w, h, r, css, blur, tier }`。`surface` 必须是 `glass-schema.js` 里已有的面；**`r` 必须与该元素 CSS 的圆角完全一致**，否则会看到双重边。
2. `node scripts/build-glass.mjs && node scripts/build-css.mjs`。
3. Rust 侧写 `data-glass="<id>"`。
4. 截图确认：`node scripts/shot-el.mjs <url> "<selector>" out.png 6`。

### 4.3 改调色板 / 观感

- 颜色、尺寸、模糊：`控件/css/src/tokens.css`（只改变量，不加规则）。
- 折射强度、色散、高光：`scripts/glass/glass-schema.js` → 重跑 `build-optics.mjs` + `build-glass.mjs`。
- **先用「调节」页试**：九个滑块实时改 CSS 变量，调满意了把输出框里的值抄进 `tokens.css`，再重跑构建。这是改默认值的唯一推荐路径——直接手改数字往往要来回七八次。

## 5. 验证

### 5.1 编译底线（提交前必跑）

```sh
cargo test  -p glass-design --lib                                                    # 30 passed
cargo check -p glass-design -p glass-design-gallery --target wasm32-unknown-unknown  # 0 warning
cargo check -p glass-design-app                                                      # 宿主
```

### 5.2 发布包体积校验

改了 `include`、新增 `examples/` 或把 `css/src/` 挪进包，都要重跑这一条。包体积涨了而没人注意，是因为源文件一直在本地躺着，只有 `cargo package` 才知道哪些真的进了包。

```sh
cargo package -p glass-design --list --allow-dirty | wc -l    # 期望 < 120
cargo package -p glass-design --allow-dirty --no-verify       # → Packaged 84 files, 1.3MiB (405.5KiB compressed)
```

口径：

- 计数含 cargo 自动加的 4 个文件（`.cargo_vcs_info.json`、`Cargo.lock`、`Cargo.toml`、`Cargo.toml.orig`）。
- 当前基线：84 个文件 / 1.3 MiB / 压缩 405.5 KiB。文件数超 120 或压缩后超 600 KiB，说明 `css/src/` 或 `target/` 之类混进来了。
- `--allow-dirty` 只在工作区有未提交改动时加；发布前必须干净，不加它也应能过。

### 5.4 对齐类缺陷用矩形比对

肉眼在 1x 截图上会看错 2–6px（字形宽度、居中、亚像素都会骗人）。一律用 `getBoundingClientRect()` 逐列/逐行比对：

```js
const t = document.querySelector('.c-datatable');
const ths = [...t.querySelectorAll('thead th')].map(e => Math.round(e.getBoundingClientRect().x));
const tds = [...t.querySelectorAll('tbody tr')[0].children].map(e => Math.round(e.getBoundingClientRect().x));
JSON.stringify(ths) === JSON.stringify(tds);   // 必须 true
```

## 6. 排障

症状 → 原因是固定的，直接查表。

| 症状 | 原因 | 做法 |
|---|---|---|
| release wasm 27 MB | 默认带 name 段（24 MB 符号名） | `wasm-bindgen --remove-name-section --remove-producers-section` |
| 改了 CSS 页面没变 | `include_str!` 变化本机不触发重编 | 重跑 `build-css.mjs` 后 `touch 控件/src/lib.rs` |
| 某块玻璃的模糊/涂层不对，但 optics.css 明明写对了 | optics 排在 components 之前，被 `17-materials.css` 的同特异度规则覆盖 | 组装顺序必须是 tokens → base → layout → components → **optics 收尾** |
| 桌面窗口里一出现新画面，整窗像素微移（浏览器里没有） | 透明窗口 = 分层窗口，DWM 重传时按整像素对齐 | 窗口设 `transparent: false`；背景由合成渐变 `#wallpaper` 提供，不需要真透明 |
| 双击 `index.html` 白屏 | 单文件里 wasm 没内联 / 旧文件 | 重跑 `build-standalone.mjs`；Console 应有 `WASM 启动失败` 提示 |
| 面板跑到别处 / 跟着容器滚 | 祖先有 `transform` / `filter` / `backdrop-filter` 成了包含块 | 面板一律 `<Portal>` + 视口坐标 |
| 点菜单项反而把菜单关了 | 面板已 Portal 到 body，`root.contains()` 判成点外 | 判定要同时认「触发器 ∪ 面板 ∪ 子菜单」 |
| 滚一格跳两格 | 滚动锚定在撑高行增长时又补一次 | 虚拟滚动容器 `overflow-anchor: none` |
| 连按 ↓ 每 7 行被拽回中间 | `focus()` 默认把目标居中滚 | `focus({preventScroll:true})` + 自己算最小滚动 |
| 滚到底部一片空白 | `scrollTop` 超出总高，窗口 `start > total` | `window()` 把 start 夹回 total（有单测） |
| 滚轮完全不动 | 中间套了一个 `scrollHeight == clientHeight` 的滚动容器，它吃掉了事件 | 只留一个滚动容器；内层 `overflow: visible` |
| 子菜单错位或被裁 | 父面板自带 `backdrop-filter` + `overflow:hidden` | 子菜单独立 Portal + 独立 `OverlayId` |
| Esc 关掉子菜单又弹回来 | 悬停计时器在关闭之后才触发 | 关闭入口清掉本层计时器 |
| 菜单一打开第一项就亮着 | `focus_first` 默认把焦点放进第一项，而 `:focus` 与 `:hover` 同一套强调色 | 右键菜单传 `focus_first=false`（焦点给面板）；按钮菜单保持 true |
| 波浪条滚回顶部后当前项不回去 | 判定线上方一段都没越线（首段 top=146 > 140），`found` 为 None 直接 return | 把 `found` 的初值设成 `Some(0)` |
| 波浪条完全不跟随滚动 | 监听器找 `closest('.l-stage')`，但 `.c-wave` 与 `.l-stage` 是**兄弟**，找不到就退回 window，而 window 根本不滚 | 找不到祖先时再看父节点下的 `.l-stage` |
| 鼠标移开后圆钮里的图标又跳一下 | 缩放结束销毁合成层，内部 18px 图标在最后一帧重新栅格化 | `will-change: transform` 常驻 + 显式 `transform-origin: 50% 50%`；几何中心实测 dx=dy=0 |
| 描边和顶部晕光只能一起调 | 两者共用 `--lg-stroke-alpha`（0.8px 的外环与几十像素的径向晕染同源） | 拆出 `--lg-bloom`（生成器按面写入，默认等于描边），径向晕染渐变改读它；内壁白边仍跟描边 |
| 弹层出现后里面的文字/图标自己挪一下，方向和距离随位置变 | 入场动画里带 `scale`：以 transform-origin 为中心缩放，元素按「离原点多远」位移，原点又在锚点上 | 入场只动 `opacity`，几何一律不动（`15-states.css` 的 `gd-pop-in` / `gd-sheet-in`）；tooltip 的 2px 上浮同理去掉 |
| 把「描边」调到 0，某处还剩一圈 | 两处写死：胶囊 `--round` 挂的构建期贴图（高光烘死）、dock 的 `0.46` 白边与 `0.3 + 0.9×` 的亮度地板 | 贴图面改用纯 CSS 材质（圆钮走 `--circle`，不挂 `url()`）；dock 的白边/镜面环都改成乘 `--lg-stroke-alpha` |
| 悬浮导航被内容卡片盖住、点不动 | `.l-stage` 在画廊里被抬到 `z-index:1`，与库里的 `.c-dock` 同层，DOM 在后的 stage 盖住了它 | 画廊里给 `.c-dock` 提到 3（高于 stage，低于顶栏/波浪条） |
| 拖动时出现手掌指针 | 组件里写了 `cursor: grab/grabbing` | 全部删掉，回到 `default` —— 指针形状由系统给，不自绘 |
| 提示条顶部像贴了一道刘海 | 镜面 `::after` 是块独立药丸（`inset: 0.5px 12px` + 高 42%），左右直边切在圆角上 | 高光必须由形状裁：`inset: 0` + `border-radius: inherit`，两端再用横向 mask 收掉 |
| 浮层打开是硬闪、没有入场 | 迁移时只搬了退场（`[data-state="closing"]`），入场原来是 JS 弹簧 | 在 `[data-state="open"]` 上挂 keyframes（`backwards`，结束不留 transform） |
| 提示条被顶开时瞬移 | 槽位没有 FLIP：flex 重排就是一次跳 | Rust 侧记住上一次的顶边坐标，改动后补 `translateY(Δ)` 再放开 |
| 滑块拇指按下是硬跳、没有缩放动画 | `--thumb-s` 变了但拇指没写 `transition: transform` | 静止/按住两条规则各自声明 transform 的过渡（按住用带过冲的曲线） |
| 修改 `--thumb-s` 没反应 | 元素自己声明了 `--thumb-s`，盖掉从 `.c-slider` 继承来的行内值 | 兜底写成 `var(--thumb-s, 1)`，不要在拇指上声明这个变量 |
| 调节页拖一格就断 | 行结构订阅了数值，每次输入重建 Slider，拖动状态丢失 | 结构只订阅「当前面」，单元格用 `Signal::derive` 单独订阅 |
| 调节页初值全是 0 / 空 | 探针元素先 `remove` 再读 `getComputedStyle`（活对象，移除后全空） | 边挂边读，抄成快照后再移除 |
| 点外部控件没反应 | `DatePicker` / `ColorWell` 的全屏遮罩吞了点击 | 不要遮罩，改文档级 `pointerdown` 判定 |
| 虚拟列表底部多一条 4px 缝 | 0 行的撑高行仍占一个 gap | `data-rows="0"` 时 `display: none` |
| 集合虚拟化后列宽变了 | 绝对定位模式没复刻 padding/gap | 保留静态 grid + 跨行撑高行 |
| `pub mod virtual;` 编译不过 | `virtual` 是保留字 | 模块名用 `virtual_window` |
| 开第二个菜单后键盘失灵 | 被挤掉的那层在 rAF 里归还焦点，晚于新层聚焦 | 归还要过 `focus_is_free(own)` |
| 退场动画上线后连按两次 Esc 只关一层 | 第一层关闭后仍在栈上待 140ms | `Entry.closing` + `mark_closing`；取「最后一个没在退场的层」 |
| 气泡里的下拉一选项，气泡跟着关 | 下拉 Portal 到 body，气泡的「点外」认不出子层 | `bind` 把非模态面板也交给栈，按 lineage 认子树 |
| 变高列表滚动一片白 / 跳两倍 | 用「行数 × overscan」在高度差 4 倍的列表里毫无意义 | 变高一律按像素 overscan，撑高用 `offset(start)` |
| 胶囊两侧空出一大截 | 内容塞进了定宽档位（112 / 180） | 宽度跟着内容走的一律用 `CapsuleSize::Auto` |
| 文本域里显示 `<!---->` | Leptos 空标记序列化进 `<textarea>`，RCDATA 把它当正文 | 导出时按 `<textarea>…</textarea>` 剥掉（`build-static.mjs` 已做） |
| 玻璃像一块灰板 | 背景层是不透明纯色，`backdrop-filter` 只能算出同一个纯色 | 确保 `#wallpaper` 使用合成渐变背景（`data-source="demo"` / `--wallpaper`），内容面留 94% |
