# 接入手册 · 给新会话

这份文件是自包含的：一个全新的会话只要读到它，就能把一个 Tauri 2 + Leptos 项目接上 GlassDesign。**不需要发布到 crates.io，也不需要 token。**

---

## 0. 事实速查

| 项 | 值 |
|---|---|
| 仓库 | `https://github.com/Genlue/GlassDesign` |
| 固定版本 | tag `v0.8.2`（`cargo` 能解析仓库里的 `控件/` 这个 workspace 成员，已实测） |
| 库 crate | `控件/` → `glass-design`，104 个公开组件，唯一出口 `glass_design::prelude::*` |
| 宿主 crate | `host/` → `glass-design-host`，只做窗口与桌面截屏；**用浏览器预览时可以不要** |
| 技术栈 | Leptos 0.8（CSR）、wasm32-unknown-unknown、运行时不碰 DOM |
| 样式 | 默认编进 wasm，由 `install()` 注入；`bootstrap()` 已经包含这一步 |

---

## 1. 加依赖：三行，缺一不可

```toml
[dependencies]
glass-design = { git = "https://github.com/Genlue/GlassDesign", tag = "v0.8.2" }
leptos = { version = "0.8", features = ["csr"] }
wasm-bindgen = "0.2"
```

也可以让 cargo 写：
```sh
cargo add glass-design --git https://github.com/Genlue/GlassDesign --tag v0.8.2
cargo add leptos --features csr
cargo add wasm-bindgen
```

**为什么 leptos 和 wasm-bindgen 必须自己声明**：`#[component]`、`view!`、`#[wasm_bindgen]` 展开成 `::leptos::…`、`::wasm_bindgen::…` 绝对路径，指向使用方 crate 根的外部 crate。库的 re-export 只提供 `glass_design::leptos` 这个额外路径，改不了宏。只声明 `glass-design` 会得到 `E0433: cannot find leptos in the crate root`。

**别写 `leptos = "=0.8.23"` 这种精确锁**：库用 caret，你锁死就可能各拿一份 leptos，`Signal` 变成两个类型，满屏 `E0308`。

**本机要挂代理才能首次拉取**：
```sh
set https_proxy=http://127.0.0.1:7890
set CARGO_NET_GIT_FETCH_WITH_CLI=true   # libgit2 默认不吃 https_proxy
```
拉过一次后缓存在 `~/.cargo/git`，之后离线也能编。

## 2. 最小可运行

页面入口（例如 `ui/src/lib.rs`）：

```rust
use leptos::prelude::*;
use glass_design::prelude::*;

#[wasm_bindgen::prelude::wasm_bindgen(start)]
pub fn start() {
    bootstrap(App);   // 等价于 install() + Theme::provide() + 浮层栈 + mount_to_body
}

#[component]
fn App() -> impl IntoView {
    view! {
        <AppShell>
            <Main>
                <ScrollArea>
                    <Card>
                        <SectionTitle>"你好"</SectionTitle>
                        <Row label="第一行"><Badge label="已就绪" variant=BadgeVariant::Accent /></Row>
                    </Card>
                </ScrollArea>
            </Main>
        </AppShell>
    }
}
```

`bootstrap` 挂到 `body`，不需要自己准备挂载点。手写根节点的场合才用 `<GlassApp>` 或拆开的 `install()` + `Theme::provide()` + `mount_to_body()`。

配套 `index.html`（放到 Tauri 的 `frontendDist`）：

```html
<!doctype html>
<html lang="zh-CN">
<head><meta charset="utf-8"><title>App</title></head>
<body>
<script type="module">
  import init from './pkg/<crate_name>.js';
  await init();
</script>
</body>
</html>
```

构建（CLI 版本要与 `Cargo.lock` 里的 wasm-bindgen 一致，本仓库是 0.2.130；两个 `--remove-*` 不能省，否则 wasm 多 24 MB 符号名）：

```sh
cargo build -p <你的包名> --target wasm32-unknown-unknown --release
wasm-bindgen --target web --no-typescript --remove-name-section --remove-producers-section \
  --out-dir ui/pkg target/wasm32-unknown-unknown/release/<crate_name>.wasm
```

## 3. 页面骨架

```rust
view! {
    <AppShell>                                  // 根壳：顶栏跨整窗宽，不占内容列
        <Toolbar>
            <ToolbarChrome><TrafficLights /></ToolbarChrome>   // 必须是第一个子项
            <ToolbarLead><ToolbarTitle title="我的应用" subtitle="v0.8" /></ToolbarLead>
            <ToolbarPills><Capsule> … </Capsule></ToolbarPills>
        </Toolbar>
        <NavColumn>                              // 可选；删掉就是单栏
            <NavGroup>
                <NavSection label="页面" />
                <NavItem icon=IconName::HOUSE label="首页"
                    selected=Signal::derive(move || page.get() == "home")
                    on_click=Callback::new(move |_| page.set("home".into())) />
            </NavGroup>
        </NavColumn>
        <Main>
            <ScrollArea>
                <Page><PageInset><Stack>
                    <Card>
                        <SectionTitle>"设置"</SectionTitle>
                        <Row label="启用" hint="受控开关">
                            <Switch
                                checked=Signal::derive(move || on.get())
                                on_change=Callback::new(move |v| on.set(v)) />
                        </Row>
                        <Row label="名称">
                            <Field value=name placeholder="输入名字"
                                on_input=Callback::new(move |v| name.set(v)) />
                        </Row>
                    </Card>
                </Stack></PageInset></Page>
            </ScrollArea>
        </Main>
    </AppShell>
}
```

三条结构规矩：
- `Toolbar` 不是 `Main` 的子节点，它在 `.l-app` 里跨整窗宽。
- `ToolbarChrome` 必须是 `Toolbar` 的第一个子项，标题组的位移按它算。
- `PageInset` 与 `Stage` **二选一**，都给顶栏让位，叠加会多一条空白。

---

## 4. 状态与 props 约定

- **调用方持有值，组件只上报**：`value` / `checked` 传 `Signal::derive(move || …)`，变化在 `on_change` / `on_input` 里 `set` 回去。不写回，界面就不动。
- `on_input` 是输入过程中持续发，`on_change` 是提交 / 失焦 / 松手时发，别混用。
- 列表项传**结构体**（`MenuItem` / `DataColumn` / `TreeNode`…），不要传 `impl IntoView`——传了视图就没法做键盘、虚拟化和选中。
- 组件没有 `style: String` prop。要局部尺寸用语义 prop；要外观用 `class` 追加类名或 CSS 令牌。
- 少用裸 `<div class="l-*">`，用布局原语：`Stack` / `Cluster` / `Grid` / `Page` / `PageInset` / `Stage` / `Center` / `Push` / `Fill` / `Pad`。`Cluster` 的 `between` / `end`、`Pad` 的 `wide`、`Stage` 的 `flush` 是常用开关。

## 5. 三个扩展点

**自定义图标**（内置 97 个，给 24 视框的 path 片段，不含 `<svg>` 外壳）：
```rust
const LOGO: IconName = IconName::custom("<path d=\"M4 12h16\"/>");
view! { <Icon name=LOGO size=18 /> }
```
线宽由 `--ic-stroke` 控，别在 path 里写 `stroke-width`。

**主题**：
```rust
let theme = Theme::provide();                       // bootstrap 已经调过一次，这里只是取
theme.set_accent("#6e56cf");                        // 强调色走这个
theme.set_token("--r-md", "10px");                  // 改 apply() 不管的令牌：圆角/字号/字体/间距
theme.remove_token("--r-md");
```
不要用 `set_token("--accent", …)`：`apply()` 每次主题切换会重写整组 `--accent*`，而且 hover/ring 会停在旧色。

**浮层**：`Dialog` / `Select` / `Menu` / `Sheet` 全部共用一个 `OverlayHost`；`bootstrap()` 和 `AppShell` 都会提供，不要自己再造一个。任何 `position: fixed` 的浮层必须走库里的 `Portal`，留在组件 DOM 里会被 `transform` / `backdrop-filter` 的包含块坑到。

## 6. 玻璃材质的两条硬规矩

1. **尺寸必须落在档位上。** 贴图是构建期按固定尺寸烘出来的，`feImage` 不会可靠拉伸。`CapsuleSize::Round`(34×34) / `Sm`(112×34) / `Md`(180×34) / `Auto`(跟随内容，纯 CSS 涂层无折射)。宽度不固定的内容一律用 `Auto`，硬塞进 `Sm` 会变成“被拉长的圈”。还有滑块拇指 24×16、面板三档、菜单两档、Sheet、Toast。
2. **`backdrop-filter` 采不到窗口外的像素。** 玻璃折的是页面底层 `#wallpaper` 的内置合成渐变背景（`tokens.css` 的 `--wallpaper`）。无需桌面截屏或 `WDA_EXCLUDEFROMCAPTURE`，远程桌面、系统截图、录屏与任务栏预览均可正常工作。内容面保持 94% 不透明，背景只透一层气氛。

## 7. 真窗口里的壳层接线（推荐）

`glass-design-host` 不再挂载 `WDA_EXCLUDEFROMCAPTURE` 也不再进行桌面截屏（`HostOptions` / `install_with` / `capture_backdrop` 仅保留作为向后兼容 API；`install()` 为安全空操作，`capture_backdrop` 返回禁用提示），因此应用窗口可以正常参与远程桌面、系统截图、录屏与任务栏预览，也不会出现驱动黑屏。

同一 tag 再加一个依赖：

```toml
glass-design-host = { git = "https://github.com/Genlue/GlassDesign", tag = "v0.8.2" }
```

宿主 `main.rs`：

```rust
fn main() {
    tauri::Builder::default()
        .invoke_handler(glass_design_host::handlers!())
        .setup(|app| {
            glass_design_host::install(app.handle())?;
            Ok(())
        })
        .run(tauri::generate_context!())
        .expect("启动失败");
}
```

前端再做两件事：
1. `tauri.conf.json` 的 `app.withGlobalTauri` 设为 `true`；
2. 把 `host/assets/wallpaper.js` 复制到 `frontendDist`，在 `index.html` 末尾引 `<script src="wallpaper.js"></script>`。

它会在检测到 `window.__TAURI__` 时自动写上 `data-shell="host"`（去掉浏览器预览用的 10px 内缩边框，使 `.l-app` 铺满窗口），并确保 `#wallpaper` 保持使用 `tokens.css` 的内置合成渐变背景。仓库的 `template/` 是完整可编译的样板。

窗口配置照仓库 `应用/src-tauri/tauri.conf.json`：`decorations: false`、`transparent: false`。**不要为了玻璃开透明窗口**——backdrop-filter 本来就采不到窗口外，透明只会让 Windows 上的分层窗口在重传时微微位移。

## 8. 首帧与 feature

默认 `embedded` feature 把 331 KB CSS + 134 KB SVG 编进 wasm，`install()` 注入。代价是首帧要等 wasm 下载实例化才上样式。

要在 `index.html` 里直接 `<link>` 样式：

```toml
glass-design = { git = "...", tag = "v0.8.2", default-features = false }
```
```html
<link rel="stylesheet" href="/glass.css">
<script type="module">
  const defs = await (await fetch('/glass-defs.svg')).text();
  document.body.insertAdjacentHTML('beforeend', `<div hidden>${defs}</div>`);
</script>
```
`glass.css` 与 `glass-defs.svg` 在发布包的 `css/`、`assets/` 里；也可用 `glass_design::styles_css()` / `glass_defs_svg()` 在构建期落盘。收益：wasm 少 465 KB，首帧不等 wasm。

## 9. 排障

| 症状 | 原因 / 处理 |
|---|---|
| `E0433 cannot find leptos in the crate root` | 少声明 leptos / wasm-bindgen，见 §1 |
| `E0308 Signal vs Signal` | 应用侧写了 `=0.8.x` 精确锁，出现两份 leptos；改成 `"0.8"` |
| `cargo` 拉不到 GitHub | 挂 7890 代理 + `CARGO_NET_GIT_FETCH_WITH_CLI=true` |
| 升级库没生效 | 改 `tag`，然后 `cargo update -p glass-design` |
| 样式是旧的、DOM 是新的 | 两个 0.x 版本同时存在，`install()` 按 `gd-styles` 这个 id 去重，后装的静默复用旧样式；全局只保留一个版本 |
| 玻璃看着是平的 | 没有 `#wallpaper` 合成渐变背景，或者元素尺寸不在档位上 |
