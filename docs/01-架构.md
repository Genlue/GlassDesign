# 01 · 架构

> 这份文档只描述**现在是什么**。改动任何一条链之前，先确认你动的是哪一条。

---

## 1. 三层与单向依赖

```text
scripts/  ──生成──▶ 控件/css/glass.css、控件/assets/glass-defs.svg、控件/src/base/icon.rs
   │                            │
   │                            ▼  include_str! 编进 crate
   │                       控件/（crate glass-design）
   │                            │
   └──打包──▶ 应用/ui/dist ──▶ 应用/ui（Leptos 画廊）──▶ 应用/src-tauri（宿主）
```

- `控件/` 是**叶子**：只依赖 crates.io 上的 leptos / wasm-bindgen / web-sys，不依赖仓库里任何其它目录。所以它能整个文件夹拷走。
- `scripts/` 只在构建期跑，产物落进 `控件/`。改脚本不会改运行期行为，改**产物**才会。
- `应用/` 是消费者：画廊用来展示与验收，宿主只做窗口、背景截屏、托盘这类平台能力。

跨层改动（比如让组件直接请求宿主）会让 `控件/` 失去可复制性，一律不做。层与层之间只通过 **CSS 变量、`data-*`、公开 props** 通信。

---

## 2. `控件/` 内部结构

```text
控件/src/
├── lib.rs              prelude 是唯一公开出口
├── base/               跨组件的地基，不含任何控件
│   ├── install.rs       注入 <style id="gd-styles"> 与 <div id="gd-glass-defs">，幂等
│   ├── theme.rs         主题：只写 <html> 的 data-theme* 与变量
│   ├── overlay.rs       浮层栈：z 序 / Esc 逐层 / 仲裁 / 退场 / 焦点陷阱 / inert
│   ├── anchor.rs        面板几何：翻上、夹取、跟随滚动
│   ├── virtual_window.rs 窗口算法（固定行高 + 变高行两套）
│   ├── icon.rs          97 个图标的 path 表
│   ├── i18n.rs          Locale / Strings / t()
│   ├── id.rs            组件内部 id 生成
│   └── types.rs         Size 之类的小枚举
├── layout/             壳与表面，决定页面骨架
│   ├── shell.rs         AppShell / Main / ScrollArea / NavColumn / NavGroup / NavItem
│   ├── toolbar.rs       Toolbar / ToolbarChrome / ToolbarLead / ToolbarPills / Capsule
│   ├── surfaces.rs      Card / Row / SectionTitle / Divider
│   └── glass_panel.rs   真折射面板（三档）
└── widgets/            104 个组件，一个文件一族
    ├── selection.rs      列表/表格共用的选择模型（内部模块，不导出）
    └── …                 按钮 / 表单 / 数据 / 导航 / 浮层 / 状态
```

**分工原则**：`base/` 里不许出现任何业务控件；`layout/` 只管骨架与间距；`widgets/` 不直接操作 DOM 样式，只挂类名与 `data-*`。

## 3. 七条链

七条链之间只通过三样东西交互：**CSS 变量、`data-*`、公开 props**。跨链改动成本高一个量级。

### 3.1 材质链（构建期 → 静态 filter）

```text
scripts/glass/*.js ──build-glass.mjs──▶ 位移图 + 高光图 (PNG/base64)
                                     ├▶ 控件/assets/glass-defs.svg（<filter>）
                                     └▶ css/src/components/63-glass-svg.css（选择器 + backdrop-filter）
install() ──注入──▶ <style id="gd-styles"> + <div id="gd-glass-defs">
组件只写 class / data-glass ──▶ backdrop-filter: blur(…) saturate(…) url(#gd-glass-panel-480x320)
```

11 个档位：胶囊 34 / 112 / 180、滑块拇指 24×16、面板 320×220 / 480×320 / 640×420、菜单 240×200 / 240×280、Sheet 520×360、Toast 320×34。不在档位里的走 `Auto`：纯 CSS 涂层，无位移折射。

**为什么必须固定档位**：Chromium 的 `feImage` 不会按元素框拉伸贴图，尺寸不一致会出现硬切或局部不滤波。加一档的流程见 `docs/03-构建与验证.md` §4.2。

### 3.2 主题链（只写变量）

```text
Theme::provide() ──Effect──▶ <html data-theme="light|dark" data-theme-mode="system">
                             └▶ --accent* / --lg / --shadow-k / --ic-stroke / --text-on-accent
```

主题不生成任何样式规则，只改 `<html>` 上的属性与变量。两套调色板都在 `tokens.css` 里，切换是纯属性切换。

### 3.3 浮层几何链（Portal + 锚定层）

```text
组件只决定「开 / 关」
  ├▶ <Portal>            面板挂 body，脱离祖先的 transform / backdrop-filter 包含块
  └▶ Effect(open)        anchor::place_and_apply(触发器, 面板, spec)
        ├ 量内容高（临时放开 max-height）→ 下方放不下且上方更宽裕就翻上
        ├ 左右夹进视口（margin 8）→ 写 left/top/width/max-height + data-side
        └ anchor::watch：scroll(capture) + resize + ResizeObserver，rAF 合帧重算
```

坐标入口有两种：`TriggerSource::Element`（触发器就是锚点）与 `TriggerSource::Coords`（右键菜单、命令式菜单）。后者会临时插一个零尺寸幽灵锚点，让坐标走同一条通道——翻转、夹取、跟随规则完全一致。

### 3.4 仲裁链（同一串之外只留一层）

```text
新层 push_child(kind, parent, on_dismiss)
  ├ 祖先链 = chain(parent)            子菜单声明父菜单 → 父层永不被自己的子层收掉
  ├ 待收 = 非模态层 − 祖先链          模态层永不参与（对话框不互相关）
  ├ 每棵无关子树只取根 → 回调 on_dismiss
  └ 先入栈、再回调                    被收的那层要能在栈上看见新层
```

`push(kind, cb)` 等价于 `parent = None`。**父链只能显式声明**：判断不出"谁是谁的容器"，靠猜会把父菜单一起关掉。

### 3.5 虚拟化链（一份窗口算法，三处复用）

```text
scroll ──▶ window_of(容器, 行高, 总行数, OVERSCAN) ──▶ Window[start, end)
                                                       ├ 渲染 [start*cols, end*cols)
                                                       ├ 上留白 = start × 行高
                                                       └ 下留白 = (total − end) × 行高
```

行高必须固定，且 CSS 与 Rust 读同一个数（`--dt-row-h` / `--tree-row-h` / `--item-pitch` 由 prop 写进内联样式）。

**变高行是另一套**（`Heights` / `VarWindow`）：前缀和 + 二分，上下留白按像素算（`pad_top = offset(start)`）。目前只有集合的**列表布局**用它（`virtual_var_height`）：先按估计高度排，挂载后 `ResizeObserver` 实测校正。

### 3.6 焦点链

`OverlayHost`（`base/overlay.rs`）是唯一权威：z 栈、Esc 只关栈顶、模态焦点陷阱、背景 `inert`（按祖先链的兄弟逐层标记，不会冻住面板自己）、关闭归还焦点。

- 列表类组件用 roving tabindex（只有一个 `tabindex="0"`）；虚拟化后**先滚进视口再聚焦**，并 `focus({preventScroll:true})`。
- **Esc 跳过退场层**：退场动画期间那一层还在栈上（z 与遮罩还要它），但已经关闭了。`dismiss_top` 与文档级监听都取"最后一个没在退场的层"。
- **归还要过 `focus_is_free(own)`**：只在"焦点还在自己面板里，或已经空着"时才还——否则同 rank 仲裁时会把焦点从新层抢回旧层。

### 3.7 状态链

受控值走 `MaybeProp<T>`，回调用 `Option<Callback<T>>`；选择状态在 `widgets/selection.rs`（单选/多选/Shift 连选/Ctrl 切换），组件只留副本，变更后把完整选中集交回调用方。

**调用方持有值，组件只上报。** 组件内部只保留三类纯视图状态：焦点、展开、窗口。

### 3.8 文案链

```text
provide_locale(RwSignal<Locale>)   应用根调一次
  └▶ t()   use_context + get()（追踪）→ Strings
        └▶ 组件的兜底文案 / aria-label（调用方显式传值仍然优先）
```

`Strings` 全是 `&'static str`，因此 `Copy`，能塞进 context 与 Memo。没有 provider 时返回中文表。带占位符的文案用 `fill(tpl, &[("n", "3")])`。

### 3.9 背景链（材质的输入）

```text
内置合成渐变（tokens.css --wallpaper / data-source="demo"）
  └▶ #wallpaper（页面最底层）
       └▶ 玻璃的 backdrop-filter 折的就是这一层
```

`backdrop-filter` 采不到窗口外的像素，因此页底 `#wallpaper` 使用内置合成渐变背景，既提供稳定一致的液态玻璃折射底色，也彻底避免桌面截屏与 `WDA_EXCLUDEFROMCAPTURE` 在部分显卡驱动下导致的黑屏或无法被截图/录屏问题。内容面留 94% 不透明（`.l-main`），卡片再叠 84% —— 两层加起来才是"磨砂压在背景之上"。

## 4. 画廊（`应用/ui`）的结构

```text
lib.rs        壳：AppShell + Toolbar（红绿灯/标题/胶囊）+ NavColumn（九个分区）+ Main
              全局只做四件事：Theme::provide、provide_locale、右键接管、分区路由
pages/*.rs    九个分区，一个文件一页；每页只负责摆放组件，不写样式
```

「调节」页（`pages/tuner.rs`）是唯一会写 CSS 变量的页面：按 8 块玻璃面分别调 8 个实时参数（`--glass-w` / `--glass-blur-k` / `--lg-coating` / `--lg-dispersion` / `--lg-stroke-alpha` / `--lg-bloom` / `--lg-vibrancy` / `--hl-bottom`），初值从 DOM 实测，输出一张 `#gd-tuner` 样式表。它**只改当前页面**，不写盘、不进源码——调完把输出框里的那几行抄回 `optics.css` 才算改变默认值。构建期参数（band / amount / depth / …）运行期无效，只读展示。

## 5. 宿主（`应用/src-tauri`）

只做平台能力，不做界面：

- **不透明**、无边框、可拖动的窗口（`decorations: false`、`transparent: false`）。
  为什么不要透明：透明窗口在 Windows 上是分层窗口（per-pixel alpha），由 DWM 合成，
  位图在重传时会被对齐到整像素 —— 表现就是「一有新画面，整个窗口微微挪一下」。
  而透明对玻璃**没有任何帮助**：`backdrop-filter` 采不到窗口外的像素。
  背景由页面底层的合成渐变 `#wallpaper` 提供，所以窗口不需要真的透明。
- **贴边**（`html[data-shell="host"] .l-app`）：UI 铺满整个窗口，`inset: 0`、无圆角、无投影。
  库默认的 10px 内缩只是**浏览器预览**的读法（让页面读起来像桌面上的一个窗口），
  到了真窗口里那圈缝会让内容白让 10px、四边露出背景、四角的圆弧是画出来的。
  宿主在启动脚本（`wallpaper.js`）里写 `document.documentElement.dataset.shell = 'host'` 打开它。
- 不再使用 `WDA_EXCLUDEFROMCAPTURE` 或桌面 GDI 截屏（`capture_backdrop` / `install` / `install_with` 保留为兼容 API，`capture_backdrop` 返回禁用提示，`install` 为安全空操作），窗口可正常被系统截图、录屏、远程桌面与任务栏预览捕获。

红绿灯是**组件**（`TrafficLights`），宿主只提供回调——控件库不依赖 `tauri` crate。
