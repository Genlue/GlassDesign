# 02 · 组件契约

> 这份文档定义 `控件/` 对外承诺什么、不承诺什么。所有条目的主语都是**当前代码**。

---

## 1. 目标与边界

**目标**：调用方用 `view!` 拼界面，不碰 DOM、不碰全局单例、不碰测量。

- 只做桌面界面，不做路由、数据请求、状态容器、表单引擎之外的领域逻辑。
- 只承诺 Windows / WebView2 的完整视觉；macOS、Linux 承诺"可用 + CSS 兜底"（WebKit 不支持 `backdrop-filter: url()`，拿不到位移折射）。
- **承诺**类名、`data-*`、ARIA、键盘行为稳定；**不承诺** DOM 结构稳定。
- 同 major 内覆盖文件夹即可升级；不承诺跨 major 的样式兼容。

## 2. 一个完整页面

```rust
use glass_design::prelude::*;
use leptos::prelude::*;

#[component]
fn Page() -> impl IntoView {
    let query = RwSignal::new(String::new());
    let saved = RwSignal::new(false);

    view! {
        <AppShell>
            <Toolbar>
                <ToolbarChrome><TrafficLights /></ToolbarChrome>
                <ToolbarLead>
                    <ToolbarTitle title="基础控件" subtitle="按钮、输入、开关" />
                </ToolbarLead>
                <ToolbarPills>
                    <Capsule size=CapsuleSize::Md>
                        <SearchField
                            value=query
                            placeholder="搜索控件"
                            on_input=Callback::new(move |v| query.set(v))
                        />
                    </Capsule>
                </ToolbarPills>
            </Toolbar>

            <NavColumn>
                <NavGroup>
                    <NavSection label="控件" />
                    <NavItem icon=IconName::LAYOUT_GRID label="基础" selected=true />
                    <NavItem icon=IconName::SLIDERS label="表单" />
                </NavGroup>
            </NavColumn>

            <Main>
                <ScrollArea>
                    <Card>
                        <SectionTitle>"按钮"</SectionTitle>
                        <Row label="主要操作">
                            <Button
                                label="保存"
                                variant=ButtonVariant::Primary
                                on_click=Callback::new(move |_| saved.set(true))
                            />
                            <Button label="取消" variant=ButtonVariant::Plain />
                        </Row>
                        <Row label="状态" hint="保存后显示提示">
                            <Show when=move || saved.get()>
                                <Badge label="已保存" variant=BadgeVariant::Accent />
                            </Show>
                        </Row>
                    </Card>
                </ScrollArea>
                <div class="c-topveil"></div>
            </Main>
        </AppShell>
    }
}
```

四件事写在这段代码里：**布局是组件、状态是 signal、事件是 callback、没有一句 DOM 操作。**

壳的层级是固定的：`AppShell > Toolbar / NavColumn / Main(ScrollArea)`。`Toolbar` 不是 `Main` 的子节点——它在 `.l-app` 里绝对定位，跨整窗宽。

## 3. 命名与导出

- 组件名 PascalCase，与 CSS 类名一一对应：`Button` → `.c-btn`，`DataTable` → `.c-datatable`。
- props 全 snake_case；变体与尺寸用枚举，不用字符串（`ButtonVariant::Primary` 内部映射到 `c-btn--primary`）。
- 命令式助手保留动词：`toast()` / `toast_with()`。
- **`prelude` 是唯一出口**：`glass_design::prelude::*` 拿到全部公开类型；子模块只作组织手段。
- 一个控件一个文件；复合控件（`NavItem` / `NavGroup`）可同文件，但必须分别导出。

不用的后缀：`XxxWidget` / `XxxComponent`（库本身就是控件库，重复无意义）。

## 4. Props 约定

| 类别 | 类型 | 约定 |
|---|---|---|
| 文本 | `#[prop(into)] String` / `&'static str` | 短标签 `&'static str`，可拼接的 `String` |
| 响应式布尔 | `MaybeProp<bool>` | 可随 signal 变；不传时为 `false` |
| 静态布尔 | `bool` | 不会变的开关 |
| 值 | `MaybeProp<T>` | 受控值；组件只读（见 §5） |
| 事件 | `Callback<T>` | 只在用户动作时触发 |
| 列表 | `Vec<Item>` / `Signal<Vec<Item>>` | 项是结构体，不是视图（见 §4.3） |
| 样式附加 | `#[prop(into, optional)] class: String` | 只追加，不替换组件类名 |
| 节点引用 | `NodeRef<html::Div>` | 仅用于测量/聚焦，不作内容通道 |
| 插槽 | `Children` / `ChildrenFn` | 默认插槽；命名插槽用结构体字段 |

### 4.1 不暴露框架类型

`Signal` / `Callback` 是契约的一部分（调用方必须拿到它们才能驱动），其余 `leptos::` 类型一律不出现在 props 里。枚举、选项结构体都定义在 `控件/` 内。

### 4.2 不给 `style: String`

需要局部尺寸时用语义 prop（`width`、`rows`、`min_width`），由组件映射到类或 CSS 变量。Rust 里出现字面色值/字号/圆角/阴影即违规。

### 4.3 不用 `impl IntoView` 当数据通道

列表项用结构体（`MenuItem`、`DataColumn`、`CollectionItem`）。任意视图进来，组件就没法做键盘、虚拟化与选中。

### 4.4 默认值写在签名里

不藏在 CSS 里，也不靠 `Option` 的 `unwrap_or` 在三个地方各写一遍。

### 4.5 图标扩展

内置 `IconName` 是 97 项常量表。没有的图标走 `custom()`，不新增枚举分支：

```rust
const LOGO: IconName = IconName::custom("M4 12a8 8 0 1 1 16 0 8 8 0 0 1-16 0Z");

view! { <Icon name=LOGO size=20 /> }
```

- 参数是 24 视框里的 path 片段，必须 `'static`。运行期不做字符串查表，也拿不到动态拼的 path。
- 线宽、端点、连接由 `Icon` 的默认属性给（`--ic-stroke` 控制），**不要在片段里写 `stroke-width` / `linecap`**：写死会让这个图标在换主题线宽时不合群。
- 填充型图标在片段里自带 `fill`；`Icon` 只画路径，不处理多色。
- 图标 `aria-hidden="true"`，语义由父组件的 `label` / `aria-label` 提供；`custom` 不改变这一条。

## 5. 受控语义

**调用方持有值，组件只上报。**

```rust
let name = RwSignal::new(String::new());
view! {
    <Field
        value=name
        on_input=Callback::new(move |v| name.set(v))
    />
}
```

- `value` 是 `MaybeProp<T>`：传了就完全受控——**调用方不把值写回 signal，输入框就不会变**。
- `on_input` 在输入/拖动过程中发；`on_change` 在提交/失焦/松手时发。两者语义不同，不要混用。
- 程序改 `value` **不触发** `on_change`，避免回环。
- 校验状态（`invalid` / `error`）由调用方给；组件不判断业务规则（`Form` 的 `validate` 是唯一例外）。
- 禁用 / 只读 / busy 都是 props，不是方法。

少数"纯视图状态"允许组件自持并提供 `default_*` 初值：`default_selected`（`List` / `DataTable`）、`default_open`（`Menu` / `Disclosure`）、`default_expanded`（`TreeView`）。传了受控值就以受控值为准。

## 6. 复合组件与 Context

| 关系 | 例子 | 方式 |
|---|---|---|
| 父子结构 | `NavColumn` + `NavItem`、`Card` + `Row` | 纯组合，不共享状态 |
| 兄弟协作 | `Tabs` + `TabPanel`、`RadioGroup` + `Radio` | Context 传 `selected` / `name` |
| 浮层父子 | `Popover` + 里面的 `Select` | `ParentScope` 显式声明父层 |
| 表单编排 | `Form` + `FormField` | Context 收集值、串行校验 |

规则：

- Context 只在**必须跨层级**时用，能用 props 就不用。
- Context key 用私有类型，不污染调用方命名空间。
- 子项必须能在任意深度，不允许"只能直接子节点"的隐式限制。

---

## 7. 插槽

- 默认插槽 `children: Children`；需要重复渲染的用 `ChildrenFn`（`Empty` 的 action、`Dialog` 的 footer）。
- 命名插槽用结构体字段，不用元组位置：

```rust
<DataTable
    columns=columns
    rows=rows
    toolbar=view! { <Button label="新建" /> }.into_view()
/>
```

- 插槽内容不能依赖组件内部 DOM；组件也不假设插槽里有什么。

## 8. 测量与 NodeRef

Rust/WASM 没有同步布局，所有测量遵守五条：

1. **先 CSS，后测量。** 能用 grid / flex / 容器查询解决的，不写 JS 测量。
2. **测量放 `Effect` 或 `ResizeObserver`**，不放在渲染路径里。
3. **两阶段渲染**：第一帧给稳定骨架（固定行高 / 占位），测量后再定位；不允许"先渲染再跳一下"。
4. **测量结果进 signal**，由 signal 驱动样式；不直接写 `style.width`（拖拽中的临时值除外）。
5. **`NodeRef` 只给需要测量的元素**，不是每个节点都挂。

```rust
let track = NodeRef::<html::Div>::new();
Effect::new(move |_| {
    let Some(el) = track.get() else { return };
    let ro = ResizeObserver::new(move |entries, _| { /* 写进 signal */ });
    ro.observe(&el);
    on_cleanup(move || ro.disconnect());
});
```

异步渲染出来的面板（Portal 里的那些）要**等一帧再量**：`overlay::schedule()` 就是那个 rAF。

## 9. 浮层契约

所有浮层走同一个栈（`OverlayHost`），不允许组件自己管 z 序或 Esc。

| 承诺 | 说明 |
|---|---|
| z 序 | `1000 + 栈下标 × 100 + rank`，同一串里越晚开的越高 |
| Esc | 只关栈顶，跳过正在退场的层；模态与非模态一视同仁 |
| 仲裁 | 同一串之外只留一层；模态层不参与互收 |
| 父链 | 只能显式声明（`ParentScope` / `push_adopted`）；猜不出来 |
| 焦点 | 模态陷阱 + `inert` 背景 + 关闭归还（过 `focus_is_free`） |
| 几何 | `Portal` 到 body + `anchor` 视口坐标；翻上、左右夹取、跟随滚动 |
| 退场 | 关闭先播 140ms（`data-state="closing"`），再出栈 |

**红线**：任何 `position: fixed` 的面板必须 `Portal`。留在组件 DOM 里，祖先的 `transform` / `filter` / `backdrop-filter` 会成为包含块，面板跟着容器跑。

坐标入口两种：`TriggerSource::Element`（`MenuButton`，触发器即锚点）与 `TriggerSource::Coords`（`Menu` 的 `anchor=(left, top, width)`，右键菜单用这条）。

## 10. 主题契约

```rust
let theme = Theme::provide();          // 应用根调一次
theme.set_mode(ThemeMode::Dark);        // Light / Dark / System
theme.set_accent("#0a84ff");            // 强调色：走 set_accent，apply() 会重写整组 --accent*
theme.set_token("--r-md", "10px");      // 覆盖任意 --* 令牌
theme.remove_token("--r-md");           // 撤掉，回到 tokens.css
```

- 只写 `<html>` 的 `data-theme` / `data-theme-mode` 与一组变量（`--accent*`、`--lg`、`--shadow-k`、`--ic-stroke`、`--text-on-accent`）。
- **不生成任何样式规则**；两套调色板都在 `tokens.css` 里。
- 组件不感知主题，只消费变量。

**令牌覆盖的三条规矩**：

| 规矩 | 原因 |
|---|---|
| 只覆盖 `tokens.css` 里的“通用令牌”（颜色、圆角、间距、字号） | 组件内部的计算变量（`--thumb-s`、`--split`）由组件自己写，覆盖了会被下一次渲染冲掉 |
| 覆盖值写成完整值（`"10px"`），不要写成表达式 | 这是行内 `style.setProperty`，没有 CSS 解析期 |
| 撤掉用 `remove_token`，不要写回初值 | 写回初值就钉死在这一版；`remove_token` 让令牌重新跟随 `tokens.css` |

`set_token` 只落当前文档，不持久化。要记住用户选择，由应用把 kv 存下来，启动时再调一次。

## 11. 材质契约

真折射由构建期贴图完成，运行时只挂 CSS：

```css
.c-capsule[data-size="180"] {
  backdrop-filter: blur(12px) saturate(180%) url(#gd-glass-capsule-180);
}
```

| 档位 | 尺寸 | 用在哪 |
|---|---|---|
| `CapsuleSize::Round` | 34 × 34 | 只装一枚图标按钮 |
| `CapsuleSize::Sm` | 112 × 34 | 定宽短胶囊 |
| `CapsuleSize::Md` | 180 × 34 | 定宽长胶囊 |
| `CapsuleSize::Auto` | 自适应 | **宽度跟着内容走**，只走 CSS 涂层（无位移） |
| 滑块拇指 | 24 × 16 | `Slider` / `RangeSlider` |
| `GlassPanelSize` | 320×220 / 480×320 / 640×420 | 折射面板 |
| 菜单 | 240×200 / 240×280 | `MenuButton fixed_size` |
| `SheetSize::Md` | 520×360 | 模态（Sm/Lg 走纯 CSS） |
| Toast | 320×34 | `ToastHost` |

**两条规则**：

1. 贴图尺寸必须等于元素尺寸。宽度不固定的东西用 `Auto`，不要塞进固定档位——外壳比内容宽出一截，看起来就是个被拉长的圈。
2. 加档位的流程：`scripts/build-glass.mjs` 的 `SHAPES` 加一条（`id / surface / w / h / r / css / blur / tier`，`r` 必须与元素 CSS 圆角完全一致）→ 重跑 `build-glass.mjs` 与 `build-css.mjs` → 组件写 `data-glass="<id>"`。

## 12. 组件清单

104 个公开 `#[component]`（实测共 106 处，其中 2 个是 `pub(crate)` / 私有内部件），全部从 `prelude` 导出。

### 12.1 布局与表面

| 组件 | 说明 |
|---|---|
| `AppShell` / `Main` / `ScrollArea` | 应用骨架；`AppShell` 负责 `OverlayHost` 与 `ToastHost` |
| `Toolbar` / `ToolbarChrome` / `ToolbarLead` / `ToolbarPills` / `ToolbarTitle` | 顶栏四槽：窗口区、标题组、胶囊组 |
| `NavColumn` / `NavGroup` / `NavSection` / `NavItem` | 侧栏（roving tabindex） |
| `Card` / `Row` / `SectionTitle` / `Divider` | 容器、标签行、分节标题、分隔线；`Row` 的 `wide` 让控件槽吃掉剩余宽度（滑块这类长控件必开） |
| `Capsule` / `GlassPanel` | 玻璃胶囊（四档）/ 真折射面板（三档） |

**滚动条**：`ScrollArea` 与 `NavColumn` 挂载时自动换成覆盖式滚动条
（`base::scrollbar`）。原生滚动条占 16px 布局宽度，而且它那套
`*:hover::-webkit-scrollbar-thumb` 的「悬停浮现」在 Chromium 里不成立 ——
只有拇指本身被压住才看得见。自绘之后 `offsetWidth == clientWidth`，
指针进入容器就浮现，停手 900ms 淡出，拇指可拖。

自己写的滚动容器要同样的行为，调 `attach_scrollbar(scroller, host)`：
`host` 必须是**不滚动的定位祖先**（`.l-stage` → `.l-main`、`.l-nav__body` → `.l-nav`），
放进滚动容器里会跟着内容一起滚走。

### 12.9 布局原语

十个组件包住 `.l-*` 空间类。它们不新增类，只转发；调用方的 `class` 追加在后面。

| 组件 | 类 | props | 用途 |
|---|---|---|---|
| `Stack` | `l-stack` | `fill` | 纵向堆叠 |
| `Cluster` | `l-row` | `between` / `end` | 横排、垂直居中 |
| `Grid` | `l-grid` | — | 网格，列与间隙走令牌 |
| `Page` | `l-page` | — | 整页容器，自带裁剪与滚动边界 |
| `PageInset` | `l-page-inset` | — | 给顶栏那一行让位（与 `Stage` 二选一） |
| `Stage` | `l-stage` | `flush` | 主内容舞台，绝对定位铺满 |
| `Center` | `l-center` | — | 横纵居中 |
| `Push` | `l-push` | — | 撑开的空节点，把后面推右 |
| `Fill` | `l-fill` | — | 吃掉剩余空间，`min-width: 0` |
| `Pad` | `l-pad` | `wide` | 内容边距 |

规则：页面里不写 `display: flex` / `gap` / `padding`。间距档位由类名后缀给（`.l-stack--4`），需要在 Rust 侧指定时追加自建类，不改原语签名。

## 13. 边界：每个组件做到哪

**用之前先看这张表**，避免以为"没反应"是 bug。

| 组件 | 做到 | 没做 / 注意 |
|---|---|---|
| `OverlayHost` | z 栈、Esc 跳过退场层、同 rank 仲裁、退场动画、`push_adopted` 父层、`owns_descendant` 认子面板 | 非模态浮层的焦点归还要组件自己做（过 `focus_is_free`） |
| `Menu` | 子菜单每层独立 Portal + 独立入栈；坐标入口支持右键；`focus_first=false` 时不预选第一项（焦点给面板，方向键仍可用） | 子菜单跟随只监听 scroll/resize（无 ResizeObserver）；宽度按内容，无上限 |
| `Popover` | 六向翻转 + 夹取 + 跟随 | 侧向不跟随滚动 |
| `Tooltip` | Portal + 跟随锚点，`pointer-events: none` | 不参与 Esc 栈（提示不该被一次 Esc 收掉） |
| `Select` / `Combobox` / `DatePicker` / `DateRange` / `ColorWell` | Portal + `anchor`：翻上、夹取、跟随、锚点滚出视口自动关 | 宽度固定档；`DatePicker` 不能手输 |
| `DataTable` | 受控选择、服务端排序、行内编辑（提交制 + 校验钩子，输入法安全）、虚拟滚动 | 列可见性；变高行（行高必须固定） |
| `TreeView` | 单选、折叠焦点回退、虚拟化 | 多选、typeahead、`*` 展开同级、变高行 |
| `CollectionView` | Grid/List、固定行高虚拟化、列表布局变高 | 网格布局的变高行（行是隐式的） |
| `SplitView` | 两栏、比例制（`--split` 0..1）、键盘、双击复位 | 像素制、持久化、三栏以上 |
| `Inspector` | 一个 pane（`Children` 是 `FnOnce`，切页由调用方换内容） | 多视图并存 |
| `Sheet` | 三档尺寸，Md 命中贴图 | 无 busy / 脏检查 |
| `Drawer` | 左/右/底；底部可拖关 | 左右抽屉不可拖、宽度不可拖 |
| `Dialog` | 焦点陷阱、`inert`、归还、退场 | `dismissible=false` 时 Esc 与遮罩都关不掉（刻意） |
| `Form` | 提交编排、整体禁用、错误汇总 | 无字段注册表：字段不会自动跟随表单禁用 |
| `List` | `Single` / `Multiple` | 拖动排序、虚拟化 |
| `Avatar` | 首字/首字母、状态点 | 图片加载失败回退 |
| `Toast` | 全局队列、3.2s 自动消失、入场浮现、退场淡出、槽位 FLIP 挤兑 | 手动关闭（`dismiss(id)`）、hover 暂停计时 |
| `StatusBar` | item + progress | `__tasks` / `__more` / `__panel` 类保留未接 |

**没有的组件**（找不到了不用翻代码，就是没做）：`Resizer`（可拖分隔条）、`NavPair`（前进/后退胶囊）、`CardGroup`、`PropGroup`、`ListRow`。CSS 里还有几个分区没有对应 Rust 外壳。

**已知限制**：

- 23 个组件文件里还有 87 处兜底中文没接 `t()`（多为滑杆名、工具栏菜单项这类低频文案）。`aria-label` 与空态优先。
- 日期值的格式仍是 `"YYYY-MM-DD"`，只有面板标题与周表头跟语言走。
- `ColorPicker` 只有 sRGB，没有 Display P3。
- 右键菜单：库提供坐标入口（`Menu` 的 `anchor`），接管 `contextmenu` 是应用层的事（画廊里做了示范）。

## 14. 图标

```rust
<Icon name=IconName::LAYOUT_GRID size=16 />
```

- 97 个图标，24 视框，线宽由 `--ic-stroke` 控制（默认 1.4）。
- `IconName` 是常量表，编译期就没有的名字写不出来；运行期没有字符串查表。自带表里没有的用 `IconName::custom`（见 §4.5）。
- 图标 `aria-hidden="true"`，语义由父组件的 `label` / `aria-label` 提供。

## 15. 可访问性与键盘

- **Esc** 关最上层浮层；输入法组合态里的 Esc 不关。
- **Tab** 只在可见元素间移动；虚拟化列表只有一个 `tabindex="0"`（roving）。
- **方向键**：分段 / 单选 / 页签 / 菜单 / 树 / 集合都是四方向；`Home` / `End` 到首尾。
- 模态层打开时背景 `inert`，关闭归还焦点（不落在 `body`）。
- 所有可交互元素都有 `aria-label` 或可见文本；列表项带 `aria-selected` / `aria-checked` / `aria-level`。
