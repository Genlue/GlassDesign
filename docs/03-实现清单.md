### 1.7 浮层与面板

| 组件 | 说明 |
|---|---|
| `OverlayHost` | **唯一权威**：z 栈、Esc 逐层、同 rank 仲裁（lineage）、焦点陷阱与归还、背景 `inert` 计数 |
| `Dialog` | 走 `OverlayHost`：遮罩、Esc、点遮罩、焦点陷阱与归还 |
| `Sheet` | 模态面板：`Sm/Md/Lg`，Md 命中 `sheet-520x360` 贴图 |
| `Drawer` | 左/右/底抽屉；底部可拖拽关闭（80px 或 0.5px/ms） |
| `Menu` / `MenuButton` | 子菜单、勾选/危险/快捷键、typeahead、层级 Esc、`fixed_size` 玻璃档 |
| `Popover` | 六向 + 越界翻转 + 视口夹取；`role=dialog aria-modal=false` |
| `Tooltip` | hover 400ms / focus 立即；`aria-describedby`；不抢焦点 |
| `toast` / `toast_with` / `ToastHost` | 全局队列，3.2s 自动消失 |
| `SplitView` | 两栏、比例制（`--split` 0..1）、拖拽 + 键盘 + 双击复位 + 折叠 |
| `StatusBar` / `StatusItem` / `StatusProgress` | 状态栏左右组、带色调的 live 项、任务进度（0..1） |

浮层几何不在组件里，统一在 `base/anchor.rs`：`AnchorSpec`（dropdown / bubble）+ `place_and_apply` +
`watch`。所有面板都 `Portal` 到 body、按视口坐标定位，`data-side` 记录翻上还是翻下。

虚拟化同理，算法在 `base/virtual_window.rs`：`window / window_of / clamp` + `Window::offset/tail`。
`DataTable`、`TreeView`、`CollectionView` 三个都走这一份，边界（`total=0`、视口未布局、`scrollTop` 越界）
只在一处维护，另有 5 个单测钉住。

## 2. 简化边界（必须知道）

| 控件 | 当前做到 | 没做 / 注意 |
|---|---|---|
| `OverlayHost` | z = `1000 + 栈下标×100 + rank`；Esc 只关栈顶；新层入栈时请出祖先链以外的**非模态**层（模态不参与仲裁）；`bind` 只对模态生效 | 父链只能由组件**显式声明**（目前只有 Menu 子菜单用 `push_child`）：`Popover` 里再开下拉会被当成无关浮层，连着气泡一起收；没有退出动画 |
| `Menu` | 子菜单每层单独 Portal + 单独入栈；宽度按内容；翻上/夹取走 `anchor` | 右键菜单、多选 `menuitemcheckbox`；子菜单跟随无 ResizeObserver |
| `Popover` | 六向翻转 + 夹取 + 跟随滚动/resize（Portal） | 侧向不滚动（`scroll:false`） |
| `Select` / `Combobox` / `DatePicker` / `ColorWell` | Portal + `anchor`：翻上、夹取、跟随滚动、锚点滚出视口自动关 | `DatePicker` 不能手输；宽度固定档 |
| `DataTable` | 选择非受控（`default_selected` 只做初值）；本地排序；虚拟行要求固定行高 | 行内编辑、列可见性、服务端排序协议、受控选择 |
| `TreeView` | 单选；折叠后焦点回退（rAF 搬焦点）；虚拟化只在 `max_height>0` 时启用，焦点会先滚进视口再聚焦 | 多选、typeahead、`*` 展开同级；变高行 |
| `CollectionView` | 静态排布（`data-static`）+ Grid/List；虚拟化时 `virtual_row_height` 是**行距**（项高 + gap），项高被钉死 | 变高项（多行文本/图片撑高）不支持 |
| `SplitView` | 两栏、比例制 | 像素制、持久化、三栏以上；`--split` 与 CSS `--pane-size` 必须同改 |
| `Inspector` | 一个 pane（`Children` 是 `FnOnce`） | 多视图并存 |
| `StatusBar` | item + progress | `__tasks` / `__more` / `__panel` 类保留未接 |
| `Sheet` | Md 命中贴图 | Sm/Lg 走纯 CSS；无 busy/脏检查 |
| `Drawer` | 底部可拖关 | 左右抽屉不可拖、宽度不可拖 |
| `Dialog` | 焦点陷阱、`inert`、归还 | 退出动画；`dismissible=false` 时 Esc/遮罩都关不掉 |
| `Form` | 提交编排、整体禁用、错误汇总 | 字段注册表（字段不会自动跟随禁用） |
| `List` | `Single` / `Multiple` | 拖动排序、虚拟化 |
| `Avatar` | 首字/首字母 | 图片加载失败回退 |
| `Tooltip` | Portal + 跟随锚点、`pointer-events:none` | 不参与 Esc 栈（提示不该被一次 Esc 收掉）；深栈里可能不是最顶层 |
| `Toast` | 队列、自动消失 | FLIP 补间、并发槽位、手动关闭 |
