## 2. 简化边界（必须知道）

| 控件 | 当前做到 | 没做 |
|---|---|---|
| `Table` | 字符串单元格、排序回调、单行选中 | 列宽/列序拖拽、虚拟行、就地编辑、自定义 render |
| `List` | 单选、roving tabindex | Shift 连选、Ctrl 切换、多选 |
| `Dialog` | Esc、遮罩、打开聚焦 | 完整焦点陷阱、背景 `inert`、焦点归还、多层栈 |
| `Select` | 点击/Esc/点外关闭、固定定位 | 键盘 typeahead、子菜单、向上翻转 |
| `Tabs` | 键盘切换、关闭 | HTML5 拖拽重排、panel 联动 |
| `Slider` | 拖动/键盘/量化 | marks、刻度、RangeSlider 双拇指 |
| `Toast` | 队列、自动消失 | FLIP 补间、并发槽位动画、手动关闭 |
| `FormField` | 显示错误 | 自动给子控件写 `aria-describedby` / `aria-invalid` |
| `Avatar` | 首字/首字母 | 图片加载失败回退、P3 色彩空间 |

## 5. 下一批入口

P3 建议顺序：

1. `RangeSlider` → `NumberField` 已就位，补双拇指状态机。
2. `Combobox` → 复用 `Select` 的固定定位与键盘模型。
3. `DatePicker` / `TimePicker` → 日期网格 + 分段光标。
4. `DataTable` → 在 `Table` 上叠加列宽、列序、虚拟行。
5. `TreeView` / `CollectionView` → 先非虚拟，再虚拟化。
6. 独立 `Menu` / `Popover` / `Tooltip` → 抽 `OverlayHost` 单栈。
7. `Inspector` / `SplitView` / `StatusBar` → 面板组合。
