# 变更记录

## 0.7.0 · 2026-11-16

P4 收官：把「账本里剩下的能力项」一次做完。四组改动，行为有变化的地方逐条标出。

### 1. `DataTable` 三件套（受控选择 / 服务端排序 / 行内编辑）

- 新增 `selected: MaybeProp<Vec<String>>`：传了就是受控（渲染只认它，点击只上报）；
  不传继续走内部状态 + `default_selected`，与 0.6.0 完全一致。
- 新增 `SortSpec { key, dir }` + `sort` / `on_sort_change`：传了回调就**不本地排序**，
  `rows` 由调用方按自己的顺序给；表头只画箭头、只上报。没传就还是本地三段循环。
- 新增 `DataColumn::editable()` + `on_cell_commit(CellEdit)` + `validate(CellEdit) -> Option<String>`：
  双击 / Enter / F2 进编辑，Enter 或失焦提交、Esc 取消；**输入法组合态里的 Enter 不提交**；
  校验不过保持编辑态并挂 `.c-datatable__cell-error`。编辑不改变行高（虚拟化的前提）。
- 选择语义按桌面惯例：单击 = 只选这一行，Ctrl/Cmd = 切换，Shift = 连选，Ctrl+A = 全选。

### 2. 变高行虚拟化（前缀和 + 二分）

- `base/virtual_window.rs` 新增 `Heights` / `VarWindow`：`offset / height / set / index_at / window`，
  上下留白按**像素**算（不再是「行数 × 行高」）。固定行高那套 API 与 5 个单测原样保留。
- `CollectionView` 新增 `virtual_var_height`（**仅列表布局 + `max_height > 0` 生效**）：
  先按 `item_height` 估计、挂载后用 `ResizeObserver` 实测校正，撑高行改用 `pad_top` / `pad_bottom`。
  网格布局的「行」是隐式的，不接。

### 3. 日期 / 时间区间

- 新增 `DateRange`：单月面板、两次点击定起止、自动交换非法区间、悬停预览、键盘全套；
  面板 Portal + `anchor` 定位。
- 新增 `TimeRange`：允许跨零点（23:30 → 01:00 合法）。
- `TimePicker` 新增 `step_secs`（15/30/60）、`show_seconds`、`grid`（网格布局）。
  **不传时行为与 0.6.0 完全一致。**

### 4. 浮层：退场动画 + 父链

- 五个浮层（菜单 / 气泡 / 对话框 / 面板 / 抽屉）关闭时先播 `EXIT_MS = 140ms` 退场，
  再出栈；`data-state="closing"`。重开会作废待执行的出栈（`ExitGate` 票据）。
- 栈新增 `mark_closing`：Esc 跳过正在退场的层。**没有它，140ms 内连按两次 Esc 只关一层。**
- 栈新增 `push_adopted` + `ParentScope`：`Popover` / `Sheet` 的面板把自身句柄放进 context，
  里面的 `Select` / `Combobox` / `DatePicker` / `DateRange` / `ColorWell` 自动认它当父层。
- 栈新增 `owns_descendant` + 非模态面板 `bind`：点下拉的选项不再把气泡一起收掉
  （面板已 Portal 到 body，祖先关系只能靠 lineage 认）。

### 5. 国际化基建

- 新增 `base/i18n.rs`：`Locale`（默认中文）、`Strings`（68 个字段，`ZH_CN` / `EN` 两张表）、
  `provide_locale`、`t()`、`fill()`。**不调用 `provide_locale` 时全库文案与 0.6.0 逐字一致。**
- 已迁移 8 族：菜单 / 对话框 / 面板 / 抽屉 / 气泡的 `aria-label` 兜底，下拉与组合框占位，
  日期与时间的月标题·周表头·今天·清除，数据表空态·行数·已选·编辑，分页，集合与树空态，文件选择。
- 画廊右上角加「中 / EN」切换；切换后上述文案立刻变。

### 已知限制

- 仍有 23 个组件文件、87 处中文字面量没进表（`color_picker` 的滑杆名、`toolbar_customization`
  的菜单项、`document_tabs` 的部分提示等）。**它们都是"没接到 `t()` 的兜底文案"**，不是新功能。
- `DataTable` 的行内编辑是「提交制」：`on_cell_commit` 只给值，接受与否由调用方决定；
  组件不会替你改 `rows`（换掉 `rows` 会重挂表格，列宽/滚动位置会重置）。
- 变高行的高度是**实测缓存**：内容在挂载后被异步改高（图片加载完）需要调用方重挂或触发一次滚动。
- 日期值仍是 `"YYYY-MM-DD"` 字符串，没有做本地化格式（只有面板标题与周表头跟语言走）。

## 0.6.0 · 2026-11-16

P4 第三项：同 rank 单开仲裁。**行为有变化**：两个菜单不再可能同时开着。

- `base/overlay.rs`：`Entry` 增加 `parent`（父层 id），新增 `OverlayHost::push_child(kind, parent, on_dismiss)`；
  `push` 等价于「父层为空」。入栈时按 lineage 仲裁：
  - 保留新层的**祖先链**，其余**非模态**层全部请出（回调它们的 `on_dismiss`）；
  - 每棵无关子树只回调**根**，父层收起会带着子层一起收，避免同一组件被改两次状态；
  - **模态层不参与仲裁**：菜单不因为弹了个对话框就被别人收掉，对话框之间也不互相收。
- `Menu`：子菜单用 `push_child` 声明父层（父层 id 沿 `build_panel` 逐层传下去，`untracked` 只读一次）。
  于是「打开子菜单」不会把父菜单收掉，「打开另一个根菜单」仍然会。
- `base/overlay.rs` 新增 `focus_is_free(own)`：归还焦点前的最后一问。被仲裁关掉的那一层，
  新层早已入栈但焦点要到下一帧才搬进去 —— 判定放在真正 `focus()` 的那一帧，且看 DOM 不看栈。
  `Menu` / `Popover` 的归还路径都过这道闸，否则会把焦点抢回自己的触发器，新菜单的键盘直接失效。
- 画廊「浮层」页「菜单」一节补一段说明：同 rank 单开 + lineage 的区别。

### 已知限制

- 父链只能**显式声明**。目前只有 `Menu` 的子菜单用了 `push_child`；`Popover` 里再放一个
  `Select` / `DatePicker` 会被当成「无关浮层」，点开会连着气泡一起收掉。需要时给
  `Popover` 加 `parent` prop（同一套 `push_child` 就够，不必再改栈）。
- 被请出的层若忽略 `on_dismiss`（调用方把 `open` 写成常量 `true`），仲裁只能报一次，收不掉它。
  组件不会替调用方改状态 —— 这是「状态在调用方」的代价。

## 0.5.0 · 2026-11-15

P4 第二项：虚拟化抽公共层，树与集合跟上。**纯增量**，不传新 prop 时行为与 0.4.0 完全一致。

- 新增 `base/virtual_window.rs`：`Window`（行号区间）+ `window / window_of / clamp` +
  `offset / tail`（上下留白）。5 个单测覆盖空集、视口未布局、跟随滚动、越界夹取、收缩后夹取。
- `DataTable` 改用它（删掉本地 `OVERSCAN` 与手写 `floor/ceil`），行为不变。
- `TreeView` 新增 `virtual_row_height` / `max_height`：传了才启用。行高写进 `--tree-row-h`，
  与窗口数学共用同一个数；上下用 `.c-tree__spacer` 撑高；焦点先滚进视口再聚焦
  （`focus({preventScroll:true})`），滚出窗口后焦点丢到 body 时下一帧回收。
- `CollectionView` 新增 `virtual_row_height`（**行距** = 项高 + gap）/ `max_height`：按行窗口 +
  两个 `grid-column:1/-1` 的撑高行，保留静态 grid 的全部几何；列宽/圆角/选中底色零改动。
- 两处 `overflow-anchor: none`：否则滚动锚定会在撑高行增长时再补一次，一次滚动跳两倍。
- 画廊「数据」页新增「万级数据（虚拟滚动）」：2000 行树（DOM 216 个元素）+ 2000 项网格（DOM 171 个）。

### 已知限制

- 行高必须固定；变高行（多行文本、图片撑高）不在这一层的能力范围内。
- 集合的 `virtual_row_height` 是行距，列表模式要给 ≥ 内容自然高度 + gap（默认 `item_h=32` 时约 44）。
- 虚拟模式下集合项高被钉死，内容超出会裁掉（与原 grid 的 `overflow:hidden` 同义）。
- 树/集合的虚拟化只在 `max_height > 0` 时启用；不传就还是「由外部容器给高度、全量渲染」。

## 0.4.0 · 2026-11-15

P4 第一项：浮层几何统一。**行为有变化**，升级时注意。

- 新增 `base/anchor.rs`：锚定浮层的定位与跟随。`AnchorSpec::dropdown()`（同宽 + 内部滚动）/
  `AnchorSpec::bubble()`（按内容宽 + 不滚动）；`place_and_apply` 负责翻上、左右夹取（margin 8）、
  写 `position/left/top/width/max-height/overflow-y` 与 `data-side`；`watch` 用 scroll(capture) +
  resize + ResizeObserver 合帧重算，锚点滚出视口时回调关闭。
- **所有锚定面板改为 `<Portal>` 挂 body + 视口坐标**：`Select`、`Combobox`、`DatePicker`、
  `ColorWell`、`Menu` / `MenuButton`（含子菜单）、`Popover`、`Tooltip`。
  根治「祖先带 `transform` / `filter` / `backdrop-filter` 时 fixed 以祖先为包含块」的定位错位。
- 随之带来的行为变化：
  - 面板现在**会跟随滚动/resize**；锚点被滚出视口时自动关闭（提示条除外，跟着走）。
  - `Select` / `Combobox` / `DatePicker` / `ColorWell` 现在**放不下会向上翻**，不再一律向下。
  - 点外关闭改为同时判定「触发器 ∪ 面板」两棵子树（面板已不在组件 DOM 里）。
  - `Tooltip` 不再压入 Esc 栈（一次 Esc 不会再把提示收掉）。
  - `DatePicker` / `ColorWell` 的全屏遮罩层删除，改为文档级 `pointerdown` 判定：
    点外部控件会「既关面板又触发该控件」，不再被遮罩吞掉。
- `Menu` 子菜单每层独立 Portal + 独立 `OverlayId`，左右翻由 `menu.rs` 自己判，纵向走 `anchor`。
  `ToolbarOverflow` 删掉自己的 `Portal` 包裹（Menu 自带）。
- 画廊「浮层」页新增「滤镜容器里」一节：`transform` 容器内的下拉/菜单/气泡，作为回归护栏。
- 画廊六个页面的副标题加 `white-space:normal`，窄窗口不再截断。

### 已知限制

- `OverlayHost` 仍不做同 rank 单开仲裁（两个菜单可以同时开）。
- 子菜单跟随只监听 scroll/resize，没有 ResizeObserver。
- `Popover` 侧向展开时不滚动（`scroll:false`），极长内容会画出盒子。
- 面板关闭后仍常驻 body（`display:none`），每个实例留一个空 Portal 容器。

## 0.3.0 · 2026-11-15

P3 收口：把旧库剩下的 37 个组件全部迁完，补齐浮层基础设施，画廊扩到八个分区。

- **浮层基础设施**：`OverlayHost`（z 栈 / Esc 逐层 / 焦点陷阱与归还 / 背景 `inert`）、`GlassPanel`
  （含 `P320x220`、`P480x320`、`P640x420` 三档真折射面板）。
- **表单数值**：`RangeSlider`（双拇指、就近取手、不互换）、`Combobox`（可输可选、`aria-activedescendant`）、
  `TokenField`（去重 / 上限 / 粘贴拆分）、`DatePicker`（月网格 + 全键盘 + min/max）、
  `TimePicker`（24h / 12h 分段）、`Form` + `FormActions`（提交编排与表单级错误）。
- **外观**：`ColorWell`、`Swatch`、`Swatches`、`ColorPicker`（SV / 色相 / alpha / HEX / RGB / 吸管）、
  `FilePicker`、`DropZone`。
- **数据**：`DataTable`（列宽拖拽、列序重排、本地排序、Ctrl/Shift 选择、固定行高虚拟滚动）、
  `TreeView`、`CollectionView`；`List` 增加多选（`ListSelection`）。
- **浮层**：`Menu` / `MenuButton`（子菜单、typeahead、层级 Esc）、`Popover`（六向 + 越界翻转）、
  `Tooltip`、`Sheet`（Md 档命中 `sheet-520x360` 贴图）、`Drawer`（右侧与底部抽屉，底部可拖拽关闭）；
  `Dialog` 升级为统一走 `OverlayHost`。
- **面板**：`Inspector`、`PropList`、`PropRow`、`Outline`、`SplitView`（比例制 + 折叠 + 键盘）、
  `StatusBar` / `StatusItem` / `StatusProgress`。
- **导航**：`NavDock`、`DocumentTabs`（拖拽重排 + `Ctrl+W`）、`NavSearch`（`Ctrl+K` 聚焦）、
  `ToolbarOverflow`（实测宽度收纳）、`ToolbarCustomization`（拖拽排序 + `localStorage`）。
- 画廊扩到八个分区：基础 / 表单 / 外观 / 数据 / 导航 / 面板 / 工具栏 / 浮层。
- 构建：`wasm-bindgen` 增加 `--remove-name-section --remove-producers-section`，
  release wasm 27.9 MB → 2.75 MB（name 段占 24 MB）。
- CSS 新增/追加：`41`（图标位、焦点环）、`42`、`45`（`data-static`）、`48`（比例分栏）、
  `51`（`data-over`）、`52`（拖拽/落点态）、`57`、`60`、`62`、`13`（菜单内部滚动）。

### 已知限制

- 虚拟滚动只在 `DataTable` 落地；`CollectionView` 一次性渲染全部项。
- 弹层一律「打开时定位、开完不跟随滚动 / resize / 翻转再算」，除 `Popover` 有六向翻转。
- `Combobox` / `DatePicker` / `ColorWell` 只做向下展开，不向上翻转。
- `DataTable` 行内编辑、`TreeView` 多选与 typeahead、`ToolbarCustomization` 拖到边缘自动滚动未做。
- 真折射只在 11 个固定尺寸档成立；`Sheet` 只有 Md 档命中贴图，其余档走纯 CSS 材质。
