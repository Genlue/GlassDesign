# 变更记录

## 0.2.0 · 2026-11-15

P2 基础控件。

- 新增：Segmented、Checkbox、RadioGroup、Slider、Stepper、NumberField、TextArea、SearchField、
  Select、FormField、Badge、Chip、Avatar、ProgressRing、Progress、Spinner、Skeleton、Empty、
  InlineMessage、List、Table、Disclosure、Tabs、Breadcrumb、Pagination、Dialog、Toast、ToastHost。
- 画廊扩展为五个分区：基础 / 表单 / 数据 / 导航 / 浮层。
- 下拉改为固定定位，避开卡片的 overflow 裁剪。
- 表头排序、分页、页签、提示条自动消失、表单校验接入画廊断言。
- CSS 新增 `64-slider-leptos.css`：滑块不依赖 JS 写入 `--travel`。

### 已知限制

- 真折射只在胶囊 34/112/180 三档与滑块拇指成立。
- 面板 / 菜单 / 模态 / 提示条的尺寸档尚未建立。
- Dialog 没有完整焦点陷阱与焦点归还；List 只有单选；Table 没有虚拟化。
- OS 级透明窗口、无边框阴影、拖拽区还没有实机截图。

## 0.1.0 · 2026-11-15

首个 P1 骨架。

- 新增 Rust 组件：Button / IconButton / Field / Switch / Card / Row / SectionTitle / Divider /
  AppShell / Main / ScrollArea / NavColumn / NavGroup / NavSection / NavItem /
  Toolbar / ToolbarLead / ToolbarPills / ToolbarTitle / Capsule。
- 材质改为构建期预计算贴图 + 静态 SVG filter；运行时不注入 JavaScript、不使用 canvas/WebGL。
- 玻璃尺寸档：`CapsuleSize::Round`（34×34）、`Sm`（112×34）、`Md`（180×34）；`Auto` 走纯 CSS 兜底。
- `install()` 注入 `css/glass.css` 与 `assets/glass-defs.svg`，幂等。
- 主题只写 CSS 变量：`data-theme` / `--accent*` / `--lg` / `--shadow-k` / `--ic-stroke`。

### 已知限制

- 真折射只在固定尺寸档成立；自适应宽度没有位移滤镜。
- 面板 / 菜单 / 模态 / 提示条的尺寸档尚未建立，暂时只有胶囊与滑块拇指。
- OS 级透明窗口、无边框阴影、拖拽区还没有实机截图。
