# 变更记录

## 0.3.0 · 2026-11-15

P3 收口：把旧库剩下的 37 个组件全部迁完，补齐浮层基础设施，画廊扩到八个分区。

- **浮层基础设施**：`OverlayHost`（z 栈 / Esc 逐层 / 焦点陷阱与归还 / 背景 `inert`）、`GlassPanel`
  （含 `P320x220`、`P480x320`、`P640x420` 三档真折射面板）。
- **表单数值**：`RangeSlider`（双拇指、就近取手、不互换）、`Combobox`（可输可选、`aria-activedescendant`）、
  `TokenField`（去重 / 上限 / 粘贴拆分）、`DatePicker`（月网格 + 全键盘 + min/max）、
  `TimePicker`（24h / 12h 分段）、`Form` + `FormActions`（提交编排与表单级错误）。
- **外观**：`ColorWell`、`Swatch`、`Swatches`、`ColorPicker`（SV / 色相 / alpha / HEX / RGB / 吸管）、
  `FilePicker`、`DropZone`。
- **数据**：`DataTable`（列宽拖拽、列序重排、本地排序、Ctrl/Shift 选择、固定行高虚拟滚动）、
  `TreeView`、`CollectionView`；`List` 增加多选（`ListSelection`）。
- **浮层**：`Menu` / `MenuButton`（子菜单、typeahead、层级 Esc）、`Popover`（六向 + 越界翻转）、
  `Tooltip`、`Sheet`（Md 档命中 `sheet-520x360` 贴图）、`Drawer`（右侧与底部抽屉，底部可拖拽关闭）；
  `Dialog` 升级为统一走 `OverlayHost`。
- **面板**：`Inspector`、`PropList`、`PropRow`、`Outline`、`SplitView`（比例制 + 折叠 + 键盘）、
  `StatusBar` / `StatusItem` / `StatusProgress`。
- **导航**：`NavDock`、`DocumentTabs`（拖拽重排 + `Ctrl+W`）、`NavSearch`（`Ctrl+K` 聚焦）、
  `ToolbarOverflow`（实测宽度收纳）、`ToolbarCustomization`（拖拽排序 + `localStorage`）。
- 画廊扩到八个分区：基础 / 表单 / 外观 / 数据 / 导航 / 面板 / 工具栏 / 浮层。
- 构建：`wasm-bindgen` 增加 `--remove-name-section --remove-producers-section`，
  release wasm 27.9 MB → 2.75 MB（name 段占 24 MB）。
- CSS 新增/追加：`41`（图标位、焦点环）、`42`、`45`（`data-static`）、`48`（比例分栏）、
  `51`（`data-over`）、`52`（拖拽/落点态）、`57`、`60`、`62`、`13`（菜单内部滚动）。

### 已知限制

- 虚拟滚动只在 `DataTable` 落地；`CollectionView` 一次性渲染全部项。
- 弹层一律「打开时定位、开完不跟随滚动 / resize / 翻转再算」，除 `Popover` 有六向翻转。
- `Combobox` / `DatePicker` / `ColorWell` 只做向下展开，不向上翻转。
- `DataTable` 行内编辑、`TreeView` 多选与 typeahead、`ToolbarCustomization` 拖到边缘自动滚动未做。
- 真折射只在 11 个固定尺寸档成立；`Sheet` 只有 Md 档命中贴图，其余档走纯 CSS 材质。

## 0.2.0 · 2026-11-15

P2 基础控件。

- 新增：Segmented、Checkbox、RadioGroup、Slider、Stepper、NumberField、TextArea、SearchField、
  Select、FormField、Badge、Chip、Avatar、ProgressRing、Progress、Spinner、Skeleton、Empty、
  InlineMessage、List、Table、Disclosure、Tabs、Breadcrumb、Pagination、Dialog、Toast、ToastHost、
  Tile、MediaTile、NavInfo、NavCard。
- 画廊扩展为五个分区：基础 / 表单 / 数据 / 导航 / 浮层。
- 下拉改为固定定位，避开卡片的 overflow 裁剪。
- 表头排序、分页、页签、提示条自动消失、表单校验接入画廊断言。
- CSS 新增 `64-slider-leptos.css`：滑块不依赖 JS 写入 `--travel`。

### 已知限制

- 真折射只在胶囊 34/112/180 三档与滑块拇指成立。
- 面板 / 菜单 / 模态 / 提示条的尺寸档尚未建立。
- Dialog 没有完整焦点陷阱与焦点归还；List 只有单选；Table 没有虚拟化。
- OS 级透明窗口、无边框阴影、拖拽区还没有实机截图。

## 0.1.0 · 2026-11-15

首个 P1 骨架。

- 新增 Rust 组件：Button / IconButton / Field / Switch / Card / Row / SectionTitle / Divider /
  AppShell / Main / ScrollArea / NavColumn / NavGroup / NavSection / NavItem /
  Toolbar / ToolbarLead / ToolbarPills / ToolbarTitle / Capsule。
- 材质改为构建期预计算贴图 + 静态 SVG filter；运行时不注入 JavaScript、不使用 canvas/WebGL。
- 玻璃尺寸档：`CapsuleSize::Round`（34×34）、`Sm`（112×34）、`Md`（180×34）；`Auto` 走纯 CSS 兜底。
- `install()` 注入 `css/glass.css` 与 `assets/glass-defs.svg`，幂等。
- 主题只写 CSS 变量：`data-theme` / `--accent*` / `--lg` / `--shadow-k` / `--ic-stroke`。

### 已知限制

- 真折射只在固定尺寸档成立；自适应宽度没有位移滤镜。
- 面板 / 菜单 / 模态 / 提示条的尺寸档尚未建立，暂时只有胶囊与滑块拇指。
- OS 级透明窗口、无边框阴影、拖拽区还没有实机截图。
